# 69. Tab 0 필수 입력 시각 강조

## 목표

후보 목록 Upload 표에서 `Company`와 `Asset`이 필수 입력값이라는 점을 사용자가 입력 전에 즉시 알 수 있게 한다.

## 작업 범위

1. Company와 Asset 열 제목에 다른 선택 입력 항목과 구별되는 `Required` 배지를 표시한다.
2. 경고색을 과도하게 사용하지 않고, 기존 대시보드의 차분한 포인트 색상과 작은 pill 형태를 사용한다.
3. 기존의 필수값 검증과 업로드 계약은 바꾸지 않는다.

## 완료 기준

- Company와 Asset만 명확한 필수 입력 표기를 가진다.
- Country, Modality 등 선택 입력은 기존의 중립적인 표시를 유지한다.
- Company 또는 Asset이 비어 있으면 기존과 동일하게 저장이 차단된다.
