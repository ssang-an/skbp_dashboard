# 81. 교차 워크플로우 댓글과 Website 연결 작업로그

- Tab 0 Listing Comment를 연구 레코드의 `Tab 0` 운영 댓글로 동기화하고, Fast Triage의 사람이 작성한 Final Comment 및 기준별 Topic Note를 같은 identity의 Full Scout Team Review Workspace로 출처별 독립 댓글로 이관했다.
- 이관 댓글은 안정적인 import key로 중복을 막으며, 관리자가 삭제하면 삭제 키를 보존해 이후 재업로드에서도 다시 생성하지 않는다. AI 생성 정성평가는 이관·Tab 0 피드에서 제외했다.
- Tab 0·1·2의 Website는 공통 운영 메타데이터로 저장하고, 재평가/관리 액션의 링크 아이콘은 한 번 클릭 시 새 탭 열기, 관리자 더블 클릭 시 주소 수정으로 동작하게 했다.
- 검증: Python 컴파일, JSON Schema 파싱, Node 문법 검사, `tests.test_step0_pipeline_metadata`, `tests.test_step0_recent_uploads` 통과.
