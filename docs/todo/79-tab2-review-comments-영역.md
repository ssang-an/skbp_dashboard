# 79. Tab2 Review Workspace Comments 영역

## 목표

Team Review Workspace의 정성 평가를 Show/Hide로 접고 펼치며, 운영성 댓글 영역은 항상 인지 가능하게 분리한다.

## 범위

1. 정성 평가 패널을 기존 Review Workspace Show/Hide 영역에 포함한다.
2. 댓글 스레드 상단에 정성 평가와 같은 제목·설명 서식의 `Comments` 안내를 둔다.
3. Comments 영역은 Show/Hide 상태와 무관하게 계속 표시한다.

## 완료 기준

- Show를 누르면 정성 평가가 보이고 Hide를 누르면 접힌다.
- Comments 제목과 OIT Review/Contact History/방문자 Comments 안내가 상시 보인다.
