# 66. Tab 0 조사값 우선 표시와 요약 필터

## 목표

Tab 0 진척 표의 Country·Modality·Target·Main indication·Stage를 가장 깊은 완료 조사 결과로 일관되게 표시하고, 진척 현황 요약 카드를 Table 필터로 사용한다.

## 작업 범위

1. 표시값 우선순위를 `Full Scout → Fast Triage → Listing`으로 명시하고 회귀 테스트한다.
2. Full Scout 완료 뒤에는 Full Scout 공식 값을 표시해 Fast Triage 값을 자연스럽게 대체한다.
3. 요약 카드 Listing·Fast Triage·Full Scout·Shortlisting을 클릭 가능한 필터로 연결한다.
4. 기존 진행 단계 다중 필터와 카드 상태를 동기화한다.
5. 각 카드 hover에 포함 범위를 설명하는 안내 문구를 제공한다.
6. 공식 조사 데이터·점수·루브릭에는 쓰기 동작을 추가하지 않는다.
