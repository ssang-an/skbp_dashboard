# 20. 유사 파이프라인 검토 모달 안내 정리

## 목적

유사 기존 Pipeline 검토 모달이 선택 절차를 처음 보는 사용자도 바로 이해할 수 있게 안내 문구와 행동 표현을 정리한다.

## 작업 범위

1. 제목을 `유사한 기존 Pipeline이 N건 있습니다.`로 변경한다.
2. 비교·덮어쓰기·선택 적용 순서를 설명하는 문구를 추가한다.
3. 안내문 속 `덮어쓰기`, `선택 적용`을 실제 버튼과 같은 아이콘 pill로 표현한다.
4. `기존 조사 결과 확인` 보조 문구를 제거한다.
5. JavaScript 구문 검사를 수행한다.

## 완료 기준

- 모달에 불필요한 보조 문구가 남지 않는다.
- 사용자가 덮어쓰기 선택 후 선택 적용을 누르는 흐름을 한눈에 이해할 수 있다.
