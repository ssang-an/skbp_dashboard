# 17. GPT 원문 리포트 가독성 정리

## 목적

GPT/ChatGPT 복사 과정에서 유입되는 내부 인용 메타태그와 HTML 줄바꿈 표기를 제거·정규화하여, 원문 리포트가 일반 사용자가 읽을 수 있는 Markdown으로 표시되게 한다.

## 범위

1. Fast Triage·Full Scout GPT 지침에 내부 인용 토큰 및 HTML 태그 금지와 실제 URL 기반 References 사용 규칙을 명시한다.
2. 새로 붙여넣는 리포트는 저장 전에 `:contentReference[oaicite:…]{…}` 등 내부 인용 메타태그를 제거하고 `<br>`을 Markdown 줄바꿈으로 변환한다.
3. 이미 저장된 원문도 화면·복사·팝업에서 같은 정규화를 적용하되, 기존 JSON 원문 데이터는 일괄 변경하지 않는다.
4. 서버 저장 경로에도 같은 안전망을 두고, 자동 정리 결과를 업로드 검토 단계에 안내한다.
5. 정규화 단위 테스트와 JavaScript 구문 검사를 수행한다.

## 비범위

- Rubric, Filter, 점수 계산, schema/Manifest 의미 및 버전 변경
- URL이 없는 내부 인용 토큰의 출처 복원

## 완료 기준

- 내부 인용 메타태그가 새 저장값과 기존 화면에 노출되지 않는다.
- `<br>`이 문자로 노출되지 않고 줄바꿈으로 표시된다.
- 실제 Markdown URL 링크와 References는 유지된다.
