# 88. Tab 0 통합 다중필터와 진행 단계 정비

## 목표

Tab 0 Listing의 검색·필터 영역을 Tab 1/2와 같은 다중 선택 드롭다운 형태로 통일한다.

## 작업 범위

1. 검색 범위를 회사·자산·타깃·Theme·Cluster까지 명시한다.
2. Country, Modality, Theme, Cluster, Main indication, Stage, 진행 단계를 Tab 1/2와 동일한 복수 선택 드롭다운으로 제공한다.
3. 진행 단계 드롭다운은 Listing, Fast Triage, Full Scout, Shortlisting을 OR 조건으로 선택하며, 요약 카드 클릭과 선택 상태를 공유한다.
4. 각 일반 필터 범주는 복수 선택 시 OR, 서로 다른 필터 범주 간에는 AND로 Listing Table을 필터링한다.
5. 요약 카드의 hover 안내가 상위 패널에 잘리지 않도록 한다.
