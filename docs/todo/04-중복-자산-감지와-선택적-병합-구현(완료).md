# 04. 중복 자산 감지와 선택적 병합 구현

## 완료 내용

- 업로드 전 workflow·회사·자산 identity를 비교하고, 공백·하이픈·leading zero 표기 차이를 같은 자산 후보로 처리한다.
- 후보가 여러 개면 Asset·Company·Stage 목록과 selector에서 병합할 기존 레코드를 직접 선택한다.
- 갱신을 선택하면 기존 stable record id를 사용하고, 신규 추가를 선택하면 기존 레코드를 건드리지 않는다.
- 기존 레코드 갱신 시 `preserve_dashboard_meta()`가 첨부, Team Review, 메모, human review, edit history를 보존한다. 기존 전문 보고서는 recoverable snapshot으로 audit trail에 남긴다.

## 검증

- backend identity normalization에서 `IL-01`과 `IL001`이 같은 alias임을 확인했다.
- `node --check src/app.js`, Python compile, `git diff --check`를 실행했다.
