# 57. Tab 1 업로드 바로가기 복구와 당일 변경 점검 (완료)

## 완료 내용

- Tab 1 `PIPELINE 업로드` 클릭 시 capture된 초기 DOM 참조에 의존하지 않고, 클릭 시점의 Data Upload panel과 GPT 입력란을 다시 찾도록 변경했다.
- Fast Triage 가이드를 먼저 적용하고 panel을 명시적으로 보인 뒤 스크롤·강조·포커스를 적용하므로, Tab 전환 뒤에도 업로드 입력란으로 이동한다.
- animation frame을 지원하지 않는 환경에서도 바로 이동하는 fallback을 추가했다.
- JavaScript cache query를 갱신해 브라우저가 이번 바로가기 수정본을 받도록 했다.

## 당일 변경 점검

- 오늘 커밋된 Fast Triage 수동 편집, 헤더 건수 표시, pasted JSON 복구, DeepSeek 재파싱 안정화, 대량 Triage 재파싱 변경이 현재 `main` 이력에 반영되어 있음을 확인했다.
- 현재의 대규모 JSON/Obsidian/wiki 변경은 사용자 데이터와 생성 산출물로 판단하여 수정·스테이징하지 않았다.
- 인앱 브라우저 연결은 현재 사용할 수 없어, UI 클릭 실측 대신 이벤트·대상·fallback을 정적 회귀 테스트로 검증했다.
