# 91. Tab 0 입력그리드 한 화면 최적화

## 완료 내용

- Tab 0 Listing 입력 테이블의 고정 최소 폭을 제거하고, 10개 열을 비율 기반으로 재배치했다.

- 모바일 폭에서만 안전한 입력 폭을 유지하기 위해 가로 스크롤을 허용한다.
