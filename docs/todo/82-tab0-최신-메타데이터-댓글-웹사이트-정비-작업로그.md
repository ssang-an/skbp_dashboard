# 82 작업 로그 — Tab 0 최신 메타데이터·댓글·웹사이트 정비

## 2026-08-22

- 작업 시작: Listing 재업로드 병합 규칙, 댓글 작성자·수정, Website 공통 동작을 점검한다.
- Listing 중복 행은 새 행의 비어 있지 않은 상세 정보 수가 기존보다 많을 때에만 충돌 필드를 최신 입력값으로 교체하고, 그 외에는 빈 필드만 보완함을 확인했다. 공식 Fast Triage·Full Scout 필드는 Tab 0 재업로드로 덮어쓰지 않는다.
- Listing 댓글의 출처·작성자 표기를 `Tab 0 Team Review`로 통일했다. Tab 0 Comment pill은 단일 클릭으로 피드를 보고, 관리자 더블클릭으로 Listing Comment를 수정한다.
- Website는 동일 Pipeline 그룹의 Tab 0·1·2가 공통 운영 메타데이터를 사용한다. 단일 클릭은 새 탭 열기, 관리자 더블클릭은 최신 URL로 교체하며 Website만 별도 변경 이력을 남기지 않는다.
