# 07 추가 정정: 요약 우선순위 목록 스크롤바

- 문제: Summary card의 Grid 높이와 `overflow`가 충돌해 Priority Pipeline/F/U Action의 10개 항목 중 아래 항목이 보이지 않고, 스크롤바도 표시되지 않았다.
- 수정: `workflow-priority-list`에 Grid 영역 높이, 항상 표시되는 세로 스크롤바, 안정적인 scrollbar gutter를 지정했다.
- 접근성: 목록을 키보드로 포커스해 스크롤할 수 있도록 region label과 `tabindex="0"`를 제공했다.
- 범위: Summary panel 자체는 계속 `overflow: hidden`이며, 스크롤은 우측 Priority/F/U 목록에만 있다.
