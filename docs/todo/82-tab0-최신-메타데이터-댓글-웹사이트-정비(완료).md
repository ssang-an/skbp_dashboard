# 82. Tab 0 최신 메타데이터·댓글·웹사이트 정비 (완료)

## 완료 결과

- Listing 중복 업로드는 새 행의 상세 정보가 더 풍부할 때만 충돌값을 교체하고, 그렇지 않으면 기존값을 보존하며 빈 필드만 채운다.
- Tab 0 Listing Comment는 `Tab 0 Team Review` 작성자로 표시되고, Tab 0 Comment pill에서 관리자 더블클릭으로 수정할 수 있다.
- Website는 동일 Pipeline 그룹의 Tab 0·Tab 1·Tab 2에서 동일 URL을 사용한다. 클릭은 사이트 열기, 관리자 더블클릭은 최신 URL 수정이며 Website 수정은 변경 이력에 기록하지 않는다.
- Tab 0은 Full Scout → Fast Triage → Listing의 표시 우선순위만 적용하며, 공식 조사값 자체를 Tab 0 업로드로 바꾸지 않는다.

## 검증

- Listing 메타데이터 병합 및 교차 댓글 동기화 단위 테스트 통과.
