# 43. 루브릭 초기화 이력 버전 표시 (완료)

- 재평가로 해제된 수동 점수 이력에 `rubric_refresh_existing_vX` 또는 `rubric_refresh_latest_vX` 메타데이터를 남긴다.
- Fast Triage 변경 이력은 이를 `기존 루브릭 vX 점수로 초기화` 또는 `최신 루브릭 vX으로 초기화`로 표시한다.
- 기존에 저장된 재평가 이력도 현재 기록의 원본/검토 루브릭 버전으로 같은 설명을 표시한다.
- 기존 점수의 `이전값 → 공식 GPT 점수` 표기는 유지한다.

## 검증

- 기존 루브릭 복원과 버전 업그레이드 초기화 회귀 테스트를 통과했다.
