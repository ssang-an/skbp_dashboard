# 80. Tab0 표와 업로드 결과 정비

## 목표

Tab0 Listing 표를 Fast Triage/Full Scout 표와 같은 밀도와 가독성으로 맞추고, 긴 업로드 후에도 결과와 비우기 동작을 입력 영역 상단에서 바로 확인한다.

## 범위

1. Tab0 진행 표의 고정 열 폭·헤더 서체를 정비하고 긴 Company 값은 셀 안에서 줄바꿈한다.
2. Listing import 결과를 입력 그리드 상단에 지속 표시하고, 비우기 control을 같은 상단 도구막대로 이동한다.
3. 대기열 중복의 빈 필드 보완·더 풍부한 행 갱신·운영 메타데이터 누적 결과를 표시한다.
4. 동일 Listing을 다시 올릴 때 신규 Comment는 중복되지 않는 한 줄바꿈 누적한다.

## 완료 기준

- Company가 Country 열을 침범하지 않는다.
- 업로드 결과는 입력 그리드 위에서 확인할 수 있고, 비우기 후에도 마지막 결과는 유지된다.
- Full Scout/ Fast Triage 공식 필드는 Tab0 재입력으로 변경되지 않는다.
