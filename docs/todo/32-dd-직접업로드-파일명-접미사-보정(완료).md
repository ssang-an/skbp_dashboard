# 32. DD 직접 업로드 파일명 접미사 보정 (완료)

## 완료 내용

- DD pill로 직접 올린 파일은 파일명에 DD/DD Report가 없으면 확장자 앞에 `_DD`를 붙인다.
- 예를 들어 `3. IR_쓰리브룩스 NCDP.pdf`를 DD로 올리면 `3. IR_쓰리브룩스 NCDP_DD.pdf`로 저장·표시된다.
- 원본 이름에 IR/NCDP/ADMET 등이 있어도 선택한 DD 유형이 없으면 DD 접미사를 추가하며, DD가 이미 있으면 중복으로 붙이지 않는다.
- 서버와 클라이언트 모두 `_DD`를 DD Partner Material로 인식한다.
