# 06. 관리자 인라인 편집과 재평가 흐름 구현

## 완료 내용

- canonical stage 목록을 사용하는 admin-only table dropdown을 Tab 1·2·3에 추가했다. user는 읽기 전용 stage를 본다.
- 서버 manual-review endpoint는 admin/developer만 허용하며 stage와 target 변경을 canonical/length 검증하고 audit history에 남긴다.
- 기존 score/status/total override 및 rubric refresh도 동일한 admin 권한 강제를 사용한다.
- stage 수정은 persisted `structured_table.development_stage`를 직접 갱신하므로 Tab 3가 같은 record를 통해 즉시 동기화된다.
