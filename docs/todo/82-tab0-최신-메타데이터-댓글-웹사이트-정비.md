# 82. Tab 0 최신 메타데이터·댓글·웹사이트 정비

## 목표

- Listing 재업로드의 정보량 우선 병합 규칙을 사용자에게 일관되게 안내한다.
- Listing 댓글 작성자를 `Tab 0 Team Review`로 통일하고, Tab 0에서 직접 수정할 수 있게 한다.
- Tab 0·Fast Triage·Full Scout의 Website 링크는 동일한 주소를 사용하며, 단일 클릭은 열기·관리자 더블클릭은 수정으로 통일한다.

## 작업 순서

1. Listing 행 재업로드 시 빈 값 보완 및 더 풍부한 신규 행 우선 규칙을 점검하고 회귀 테스트를 보강한다.
2. 댓글 집계·이관 작성자 레이블을 `Tab 0 Team Review`로 정정하고 Tab 0 수정 동작을 확인한다.
3. Website 메타데이터가 동일 Pipeline 그룹의 Tab 0·1·2에 공유되는지 검증하고 문서화한다.

## 비범위

- GPT 원문, 점수, 루브릭 및 Manifest 버전은 변경하지 않는다.
