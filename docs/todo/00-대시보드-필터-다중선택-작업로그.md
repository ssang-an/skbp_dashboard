# 00. 대시보드 필터 다중선택 작업 로그

## 반영 내용

- Tab1·2 공통 Pipeline Table 필터를 원형 선택 표시가 있는 다중선택 드롭다운으로 교체한다.
- Stage와 Main indication을 포함해 Country·Modality·Theme·Cluster·Filter 1/2/3도 복수 값을 선택할 수 있다.
- 하나의 필터 안에서는 선택 값 중 하나에 맞으면 표시(OR), 서로 다른 필터끼리는 모두 충족해야 표시(AND)하도록 한다.
- 선택 수·선택 값은 탭별로 유지하고, 전체 선택을 누르면 해당 필터를 해제한다.
- Tab0의 별도 진척 현황 필터 UI는 변경하지 않는다.

## 검증

- Pipeline 필터 구조·다중 선택 매칭·원형 선택 표시를 확인하는 정적 UI 테스트를 추가한다.
