# 75. Tab 0 표 통일과 Listing 직접수정

## 범위

- Tab 0 진척 현황 표의 헤더·행 값·진행 상태 pill을 Tab 1·2 테이블 시각 언어와 통일한다.
- 아직 조사되지 않은 Listing 행에서만 관리자가 Company, Country, Asset, Modality, Target, Main indication, Stage를 인라인 수정할 수 있게 한다.
- Fast Triage 또는 Full Scout가 존재하는 행은 공식 조사값을 보호하고, 수정 시 해당 Dashboard로 안내한다.

## 검증

- JavaScript 문법, Python 컴파일, Tab 0 metadata/listing 단위 테스트를 실행한다.
