# 50. Tab 1 핵심 정보 수동 수정과 이력 표시 (완료)

## 반영 내용

- Tab 1 관리자에게 Company, Asset, Main indication의 더블클릭 텍스트 입력을 제공했다.
- Stage, Company, Asset, Main indication은 사람이 수정한 뒤 표에서 굵게 표시된다.
- Company·Asset·Main indication 저장은 `structured_table`과 요약 필드를 함께 갱신한다.
- 모든 수정은 기존 `meta.human_review.history`와 `meta.edit_history`에 저장되며, Fast Triage와 공통 상세 화면에서 사람이 수정한 필드명과 전후 값을 확인할 수 있다.
- Main indication은 기존 canonical dashboard indication 계약을 유지한다.

## 검증

- Fast Triage manual review 및 score override 회귀 테스트 통과.
- Python/JavaScript 구문 검사 통과.
