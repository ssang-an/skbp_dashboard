# 108. Tab 0 직사각형 바운더리와 Shortlisting 밀도 조정

## 목표

각 단계 node graph가 카드 전체의 직사각형 영역 안에서만 보이도록 맞추고, Shortlisting은 약한 반발·충돌로 node 겹침을 허용해 높은 밀도에서도 넘치지 않게 한다.

## 작업 범위

1. 중앙 정사각형 canvas 제한을 제거하고 카드의 전체 직사각형 그래프 영역을 사용한다.
2. 캔버스와 force layout에 동일한 카드 width·height를 전달한다.
3. Shortlisting의 many-body 반발과 collision strength/padding을 낮춘다.
4. 그래프 영역의 clipping을 유지해 카드 밖 표시를 방지한다.

## 완료 기준

- 모든 단계 node graph가 카드 크기의 직사각형 boundary에 맞는다.
- Shortlisting node는 더 조밀하게, 필요 시 부분 중첩되며 카드 밖으로 보이지 않는다.
