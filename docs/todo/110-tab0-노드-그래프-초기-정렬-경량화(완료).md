# 110. Tab 0 노드 그래프 초기 정렬 경량화

## 목표

Tab 0 G6 node graph가 초기 배치 후 빠르게 정지하도록 해 대량 Listing에서도 UI 랙을 줄인다.

## 작업 범위

1. force layout 반복 횟수를 낮춘다.
2. alpha decay/minimum 및 velocity decay를 높여 짧게 수렴시킨다.
3. node drag 후에만 필요한 범위의 force 재정렬을 유지한다.

## 완료 기준

- 최초 표시 시 짧은 배치 움직임 후 정지한다.
- Listing 대량 node에서도 지속 animation으로 인한 렌더링 부하가 줄어든다.
