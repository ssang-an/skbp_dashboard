# 108. Tab 0 직사각형 바운더리와 Shortlisting 밀도 조정 작업 로그

- G6 canvas와 force layout이 각 카드의 전체 직사각형 너비·높이를 사용하도록 변경했다.
- 기존의 중앙 정사각형 제한을 제거하고 카드 내부 clipping은 유지했다.
- Shortlisting은 many-body 반발력을 -1, collision padding을 0.25, collision strength를 0.28로 낮춰 고밀도 표시와 부분 중첩을 허용했다.
- JavaScript 문법, 대상 IA 회귀 테스트, diff whitespace 검사를 통과했다.
