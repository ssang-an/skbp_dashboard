# 50. Tab 1 핵심 정보 수동 수정과 이력 표시

## 목적

Fast Triage(Tab 1) 홈 대시보드에서 관리자가 사실 정보를 직접 정정할 수 있게 하고, 사람이 수정한 값은 표와 상세 페이지에서 명확히 식별한다.

## 작업 범위

1. Stage 수동 수정 이력을 기반으로 Stage 값을 굵게 표시한다.
2. Company, Asset, Main indication을 관리자 전용 더블클릭 인라인 텍스트 입력으로 제공한다.
3. 저장 시 `structured_table`의 사실 값을 갱신하고 필요한 요약 필드도 동기화한다.
4. 수동 수정 값은 굵게 표시하며, Fast Triage 상세 페이지와 공통 상세 페이지의 변경 이력에 사람이 수정한 필드와 전후 값이 남게 한다.
5. Main indication은 기존 대시보드의 canonical indication 계약을 유지한다.

## 완료 기준

- Tab 1 관리자 계정에서 Company, Asset, Main indication을 더블클릭해 수정할 수 있다.
- Stage 포함 네 핵심 정보는 수동 수정 후 표에서 굵게 보인다.
- 변경 이력에 회사명·자산명·Main indication·Stage의 전후 값과 수정자가 확인된다.
- 기존 점수/루브릭 계약과 Fast Triage import 구조는 변경하지 않는다.
