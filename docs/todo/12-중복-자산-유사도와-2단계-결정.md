# 12. 중복 자산 유사도와 2단계 결정

## 목표

같은 회사의 유사 자산 표기를 edit-distance로 후보화하고, 신규/기존 대상 선택과 보고서 적용 여부를 분리한 2단계 업로드 결정을 구현한다.

## 작업

- 회사 alias 동일 조건에서 normalized asset edit-distance 후보를 계산한다.
- exact/leading-zero 후보와 fuzzy 후보를 구분해 UI에 매칭 근거와 자연스러운 강조를 표시한다.
- 1단계에서 기존 후보 또는 신규를 선택하고, 2단계에서 새 보고서 적용/기존 유지/업로드 취소를 선택한다.
- 기존 유지·취소는 어떠한 record도 저장하지 않으며, 적용은 attachments/memo/Team Review/audit를 보존한다.

## 완료 기준

- fuzzy 후보가 오탐 경고로 표시되고 명시적 사용자 선택 없이는 덮어쓰지 않는다.
- 적용/기존 유지/취소의 저장 결과가 테스트된다.
