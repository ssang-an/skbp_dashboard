# 28. Shortlisting Filter 3 컨트롤 재배치

## 목표

- Filter 3의 자동 재분류 명령을 드롭다운에서 제거하고, 단일 기준 갱신 버튼만 자동 재분류 진입점으로 유지한다.
- 분류 드롭다운을 Filter 3 메타데이터 우측에 배치해 상단 공간을 압축한다.
- 그 아래 판단근거 입력란은 기본 두 줄 높이로 확장한다.

## 작업 순서

1. Detail Filter 3의 드롭다운에서 자동 재분류 항목을 제거하고, 빈 분류의 안전한 비활성 표기를 둔다.
2. Filter 3 메타데이터와 분류 드롭다운을 같은 상단 행의 좌우 영역에 배치한다.
3. 판단근거 입력란 높이와 자동 리사이즈 기준을 두 줄로 조정한다.
4. Detail JavaScript 문법과 공백 오류를 확인한다.
