# 54. 업로드 안정성 — 안전한 배치 재파싱과 오류 안내 — 완료

## 수행 결과

- Fast Triage가 이미 정상 JSON 배열로 읽힌 경우에만 11건 이상을 10건 단위로 재파싱한다.
- 각 배치는 원래 index를 기준으로 처리하며, 통합 후 원래 순서·건수·Markdown 상태 행·저장 스키마를 모두 재검증한다.
- JSON이 처음부터 파싱되지 않거나 Full Scout 단건인 경우에는 자동 분할하지 않아, 임의 경계 추정이나 사실 혼합 위험을 막았다.
- AI 재파싱 입력의 Markdown/JSON 컨텍스트 한도를 각각 120,000/80,000자로 확대했다.
- 화면은 출력 한도, JSON 구조, 저장 형식, OpenRouter 인증/권한, 요청 한도, 제공자 일시 오류를 구분해 안내한다.
- 원본 입력은 성공할 때까지 유지하며 rubric, manifest, 저장 데이터는 변경하지 않는다.
