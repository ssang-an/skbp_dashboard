# 26. Tab1 재평가 복사 아이콘 정리

## 목표

- Fast Triage(Tab1) 재평가 행의 Full Scout 지침 복사 동작을 Tab2 Team Review의 즐겨찾기처럼 작고 정돈된 원형 아이콘 버튼으로 표시한다.
- Tab0의 겹친 문서 복사 아이콘을 사용해 기능을 직관적으로 표현하되, 기존 복사 동작과 접근성 라벨은 유지한다.

## 작업 순서

1. 텍스트 기호 복사 아이콘을 공통 문서 복사 SVG로 교체한다.
2. 버튼을 30px 원형의 중립 표면 스타일로 맞추고, hover/focus 때만 accent를 적용한다.
3. JavaScript 문법 및 diff 공백 오류를 확인한다.
