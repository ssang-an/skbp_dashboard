# 07. 대시보드와 업로드 상호작용 UX 개선

## 확인 및 완료 내용

- 우측 Summary의 `workflow-priority-list`만 독립 `overflow-y:auto`로 스크롤하고, 전체 panel은 `overflow:hidden`으로 유지한다.
- Full Scout Priority Pipeline과 Shortlisting F/U Action은 모두 최신 정렬 뒤 `slice(0, 10)`으로 최대 10건만 표시한다.
- Data Upload 상태는 waiting/review-needed/validating/AI reparsing/valid/error/saved별 icon·aria-busy·문구를 이미 제공하며, 검토 모달에서 중복 대상 선택을 추가해 업로드 중복 흐름을 보완했다.
- 작은 화면에서 priority panel max-height는 230px으로 조정된다.

## 검증

- `renderWorkflowPriority()`와 `src/styles.css`의 priority panel 규칙을 대조했다.
