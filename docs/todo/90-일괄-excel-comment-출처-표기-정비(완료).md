# 90. 일괄 Excel Comment 출처 표기 정비

## 완료 내용

- Tab 0 일괄 Excel 업로드 Comment를 `일괄 Excel 업로드: Tab 0 · Listing Comment · Team Review · 날짜` 형식으로 표시한다.
- 기존 `Tab 0 Team Review`로 저장된 과거 Comment도 화면에서는 같은 Team Review 표기로 호환 처리한다.
- 관리자 직접 Listing Comment Post는 기존처럼 관리자 이름과 `Tab 0 · Listing Comment` 출처를 유지한다.
