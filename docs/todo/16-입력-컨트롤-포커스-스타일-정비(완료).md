# 16. 입력 컨트롤 포커스 스타일 정비

> 완료: 2026-08-13. 상세 반영 내역은 `16-입력-컨트롤-포커스-스타일-정비-작업로그.md`를 참조한다.

## 목표

대시보드와 Team Review Workspace의 일반 입력칸·드롭다운에서 강한 초록색 포커스 테두리와 이중 링을 제거한다.

## 작업 범위

- 일반 텍스트 입력, 날짜 입력, textarea, select와 테이블 인라인 편집 컨트롤의 focus/focus-visible 스타일을 중립 회색 테두리와 은은한 그림자로 통일한다.
- 상태 색상을 가진 select는 기존 의미색 배경을 유지하되, focus ring은 중립 회색으로 처리한다.
- Data Upload의 GPT 입력칸은 상태 의미를 유지하도록 기존의 낮은 채도 초록 focus 스타일을 유지한다.
- 버튼, 탭, 헤더, hover 전용 강조는 이 작업 범위에서 변경하지 않는다.

## 완료 기준

- 일반 입력칸을 클릭해도 강한 초록색 테두리·이중 링이 보이지 않는다.
- Data Upload 입력칸만 은은한 초록색 focus 피드백을 유지한다.
- 회귀 테스트와 JavaScript 문법 검사를 통과한다.
