# 07 정정 작업 로그

## 정정 사유

Main indication 필터가 복수 선택 스크롤 목록으로 구현되어, Stage·Modality 등 다른 공통 필터와 동일한 드롭다운 형식이어야 한다는 현재 UX 요구와 맞지 않았다. 또한 우측 Summary의 Priority Pipeline/F/U Action 목록만 스크롤되어야 한다.

## 반영 내용

- Main indication을 `전체`를 포함한 단일 선택 드롭다운으로 변경했다. 선택된 indication은 해당 indication을 포함한 모든 pipeline을 필터링한다.
- Full Scout Priority Pipeline과 Shortlisting F/U Action은 최신 갱신 시각 우선으로 정렬한 후 최대 10건만 렌더링한다.
- Summary panel은 `overflow: hidden`을 유지하고, `workflow-priority-list`에만 세로 스크롤을 적용했다.
- 작은 화면에서도 Priority/F/U Action 목록은 최대 230px 높이 안에서 독립 스크롤된다.
