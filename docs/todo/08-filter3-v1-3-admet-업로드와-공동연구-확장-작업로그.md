# 08. Filter 3 v1.3 ADMET 업로드·공동연구 확장 작업 로그

## 반영 기준

- 공동연구: modality와 무관하게 Platform Attractiveness 3이면 분류한다.
- Value Up: 확인된 IND-enabling 미만 소분자, In Vivo O, In Vitro O, ADMET Partner Materials 업로드 및 숫자 점수를 모두 요구한다. ADMET 점수는 0도 유효하며 기존 25점 이상 임계값은 제거한다.
- 공동연구 조건이 투자 또는 Value Up과 겹치면 공동연구를 최종 자동 분류로 우선한다.

## 적용 범위

- 자동 분류 서버, 기존 Shortlisting 자동 재분류 버전, Filter 3 매니페스트, Dashboard·상세 화면 판단 근거 및 스키마 설명을 v1.3 기준으로 일치시켰다.
