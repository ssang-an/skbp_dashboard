# Tab 0 안내와 Summary Dashboard 순서 정정

## 목적

Tab 0의 상단을 다른 workflow 탭과 같은 안내 구조로 복원하되, 사용자가 요청한 순서대로 `후보 목록 관리` 안내를 먼저 표시하고 그 아래에 접기/펼치기 가능한 Summary Dashboard를 둔다.

## 작업 순서

1. Listing workflow 안내 행과 i 아이콘을 복원한다.
2. 안내 행을 Summary Dashboard 위로 배치한다.
3. 기존 Summary Dashboard의 접기/펼치기 동작은 유지한다.
4. 구조 테스트와 JavaScript 문법 검사를 실행한다.
