# 58. 다중 컴퓨터 Pipeline 데이터 안전 병합 작업 로그

## 구현

- `scripts/reconcile_pipeline_records.py`를 추가했다.
- 현재 `pipeline-records.json`을 유지하고, 각 stash/snapshot에만 있는 stable record ID만 union으로 추가한다.
- 동일 ID의 JSON 내용이 다르거나 source 내부에 중복 ID가 있으면 write를 차단하고 상세 report를 남긴다.
- `--write`는 사전 원본 백업 후 원자적으로 저장한다.

## 회사 PC 실행 순서

1. `--report`를 포함한 dry-run으로 `conflicts=0`, `duplicate_id_groups=0`, `safe_to_write=yes`를 확인한다.
2. 같은 source 순서로 `--write`를 실행한다.
3. Obsidian 및 Pipeline Wiki를 재생성하고 JSON·생성 산출물을 commit/push한다.
