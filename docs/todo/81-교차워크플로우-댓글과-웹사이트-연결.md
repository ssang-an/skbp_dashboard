# 81. 교차 워크플로우 댓글과 Website 연결

## 목표

Tab 0 Listing, Tab 1 Fast Triage, Tab 2 Full Scout 사이에서 사람이 작성한 운영 댓글과 Website를 잃지 않고 이어서 관리한다.

## 범위

1. Listing Comment를 Tab 1/2 저장 시 각각의 운영 댓글 영역에 `Tab 0` 작성자로 한 번만 이관한다.
2. 동일 파이프라인의 Full Scout 저장 시 Fast Triage의 사람이 작성한 Final Comment와 기준별 의견을 출처·평가항목별 독립 댓글로 누적한다. AI 생성 답변은 제외한다.
3. 동일 출처 댓글의 재이관을 막고, 관리자만 이관 댓글을 삭제할 수 있게 한다.
4. Tab 0·1·2의 Website를 동일 운영 메타데이터로 동기화하고, 링크 아이콘의 단일 클릭은 새 탭 열기, 더블 클릭은 주소 편집으로 제공한다.

## 완료 기준

- Fast Triage의 사람 의견이 Full Scout Team Review Workspace에 `Fast Triage · Final Comment` 또는 기준명 출처로 한 번씩만 보인다.
- Tab 0 Listing Comment는 Tab 1/2에 `Tab 0` 작성자로 보이며, AI 정성평가 답변은 이관·Tab 0 피드 모두에 섞이지 않는다.
- Website를 어느 탭에서 수정해도 동일 파이프라인의 운영 Website가 일관되게 표시된다.
