# 61. Tab 0 업로드 바로가기 스크롤 복구 작업로그

## 원인

상단 바로가기 함수가 Tab 0의 별도 후보 목록 Upload 패널이 아니라 항상 Tab 1·2용 `#dataUploadPanel`을 선택했다. Tab 0에서는 이 패널이 표시 대상이 아니므로 사용자가 클릭해도 원하는 입력란으로 이동하지 않았다.

## 구현

- 활성 Tab 0 여부에 따라 패널과 입력칸 selector를 분기했다.
- Tab 0은 `#step0UploadPanel` / `#step0PasteInput`를 선택한다.
- 다른 Tab은 `#dataUploadPanel` / `#gptResponseInput`를 선택한다.
- 고정 헤더 하단을 기준으로 문서 스크롤 목표 위치를 계산해 이동한다.
