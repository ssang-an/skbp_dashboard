# 32. DD 직접 업로드 파일명 접미사 보정

## 목표

- Team Review Workspace의 DD pill로 직접 업로드한 파일은 원본 파일명에 IR·NCDP 등 다른 자료 유형이 있어도 DD 유형을 명시한다.
- DD 표기는 요청한 대로 확장자 앞 `_DD`를 사용한다.

## 작업 순서

1. 선택한 pill 유형이 파일명에 이미 포함됐는지만 검사하도록 접미사 보정 규칙을 수정한다.
2. DD의 파일명 접미사를 `DD Report`에서 `DD`로 변경하고, `_DD`도 서버·클라이언트가 DD 자료로 인식하게 한다.
3. Partner Materials 분류 회귀 테스트를 보강한다.
