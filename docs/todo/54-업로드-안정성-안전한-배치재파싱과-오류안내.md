# 54. 업로드 안정성 — 안전한 배치 재파싱과 오류 안내

## 목표

대량 Fast Triage 입력과 AI 재파싱 실패가 사용자 업로드 자체를 막지 않도록, 데이터 손실 위험이 없는 범위에서 배치 처리와 원인별 안내를 제공한다.

## 작업 범위

1. 이미 정상 JSON 배열로 파싱된 Fast Triage 11건 이상만 원래 index 기준 10건 단위로 AI 재파싱한다.
2. 각 배치 결과를 원래 순서로 합치고 전체 건수·Markdown 상태 행·저장 스키마를 다시 검증한다. 하나라도 실패하면 저장하지 않는다.
3. AI 재파싱 컨텍스트 한도를 현실적인 대량 입력 크기로 확대하되, 원문을 임의 문장 단위로 분할하지 않는다.
4. 출력 한도, JSON 구조, record 수, 스키마, 인증/권한, rate limit, 제공자 오류를 구분해 사용자에게 표시한다.

## 안전 원칙

- 파싱되지 않은 JSON 또는 Full Scout 단건은 자동 분할하지 않는다.
- 원본 입력은 성공 전까지 유지한다.
- rubric, manifest, 기존 저장 데이터는 변경하지 않는다.
