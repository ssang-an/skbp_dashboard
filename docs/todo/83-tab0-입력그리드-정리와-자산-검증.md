# 83. Tab 0 입력 그리드 정리와 자산 검증

## 목표

- Tab 0 `비우기`를 `가져오기`와 조화로운 pill 버튼으로 정리한다.
- 입력 그리드의 행별 삭제(X) 열을 제거해 표를 단순화한다.
- Asset이 빈 값, `-`, `X`/`×` 단독 표기인 행은 클라이언트와 서버 모두 업로드에서 제외한다.

## 작업 순서

1. 입력 그리드 마크업·이벤트·CSS에서 행별 삭제 열을 제거한다.
2. 비우기 버튼을 중립 secondary pill로 재설계한다.
3. Asset placeholder 검증과 회귀 테스트를 추가한다.

## 비범위

- 기존 Listing 데이터와 Fast Triage·Full Scout 공식 데이터는 변경하지 않는다.
