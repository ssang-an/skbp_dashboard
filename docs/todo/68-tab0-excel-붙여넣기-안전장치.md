# 68. Tab 0 Excel 붙여넣기 안전장치

## 목표

Tab 0 Listing 입력 표에 전체 표·부분 열을 복사해 붙여넣을 때 행 밀림, 열 제목 오입력, 범위 초과에 따른 데이터 손실을 막는다.

## 작업 범위

1. 영문·한글 열 제목을 전체 표와 단일 열 붙여넣기 모두에서 자동 제외한다.
2. 선택 범위의 내부 빈 행을 보존해 다음 Pipeline 행이 위로 당겨지지 않게 한다.
3. Contact 이후에 비어 있지 않은 값이 있으면 붙여넣기를 중단하고 명확히 안내한다.
4. Excel TSV의 따옴표 규칙을 엄격히 적용해 일반 큰따옴표와 셀 경계를 구분한다.
5. 붙여넣은 행·열 수, 대상 열, 제목 제외·빈 행 유지 결과를 입력 표 아래에 표시한다.
6. 원문·점수·루브릭·저장된 Pipeline 데이터에는 변경을 가하지 않는다.
