# 104. Tab 0 단계별 노드 클라우드 카드 통합

## 목표

Listing · Fast Triage · Full Scout · Shortlisting 요약 카드 각각에 해당 단계의 G6 노드 클라우드를 바로 붙인다. 별도 하단 그래프 패널은 제거한다.

## 작업 범위

1. 단계별 카드 내부에 독립적인 G6 캔버스를 배치한다.
2. Listing의 대량 노드도 모두 보이도록 점 크기와 충돌 반경을 단계별로 조정한다.
3. 노드가 각 카드의 고정된 그래프 영역에서만 물리적으로 움직이도록 force 중심/반발력을 조정하고 넘침을 숨긴다.
4. 그래프가 세로 중앙에 밀도 있게 모이도록 레이아웃을 보정한다.
5. 정적 회귀 테스트와 JavaScript 문법 검사를 실행한다.

## 완료 기준

- 하단 통합 그래프 박스가 없고, 각 단계 카드의 숫자 바로 아래에 해당 노드 그래프가 있다.
- Listing 700건 이상에서도 노드가 잘리지 않고 카드 밖으로 넘치지 않는다.
- 단계가 뒤로 갈수록 노드 크기는 커지되, 각 그래프는 독립적으로 움직인다.
