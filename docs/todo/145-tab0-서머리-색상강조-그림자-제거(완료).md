# Tab 0 서머리 색상 강조와 그림자 제거

## 목표

Tab 0 Summary Dashboard 카드에서 초록색 상태 강조는 유지하되, 카드 위로 드리워지는 쉐이드와 그림자 효과는 제거한다.

## 작업

- [x] 카드 hover·keyboard focus에 낮은 채도의 초록색 상태색만 적용한다.
- [x] box-shadow와 떠오르는 이동 효과는 적용하지 않는다.
