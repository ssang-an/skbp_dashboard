# 48. 코드형 자산 유사 후보 숫자 식별자 보호 (완료)

## 반영 내용

- 코드형 자산명의 숫자 식별자를 별도로 비교하도록 했다.
- `AR1001`·`AR-1001`·`AR01001`은 동일 후보로 유지한다.
- `AR1001`/`AR1002`, `AS-301`/`AS-401`처럼 숫자 식별자가 다르면 유사 후보와 확정 덮어쓰기 대상에서 제외한다.
- 같은 회사 여부는 표시·정렬 정보로만 쓰며, 서로 다른 코드 번호를 덮어쓰기 후보로 만드는 근거로 사용하지 않는다.

- `node --check src/app.js`
