# 111. Tab 0 직사각형 균일 Grid 노드 배치

## 목표

- Summary Dashboard의 각 단계 노드를 원형 force 군집이 아닌 카드 직사각형 전체에 균일 배치한다.
- Listing 700건 이상도 카드 범위를 넘지 않고, 지속적인 물리 시뮬레이션으로 인한 렌더링 부담이 없도록 한다.

## 작업

- [x] G6 `d3-force` 레이아웃을 고정 `grid` 레이아웃으로 교체했다.
- [x] 단계별 카드 가로세로 비율에 맞춰 열·행 수를 계산하고, 카드 전체 영역을 사용한다.
- [x] force drag와 초기 애니메이션을 제거하고 hover 안내는 유지한다.
- [x] 원형 느낌의 배경을 중성 사각형 카드 배경으로 정리했다.
- [x] 회귀 테스트·문법 검증·작업 로그를 남겼다.
