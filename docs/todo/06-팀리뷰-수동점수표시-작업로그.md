# 06. Team Review 수동 점수 표시 작업 로그

## 반영 내용

- `meta.human_review.overrides.scores`에 현재 criterion override가 있는지 기준으로 Team Review Workspace의 Criteria scores chip을 판정한다.
- 수동 수정된 score chip은 홈 대시보드 score 입력과 같은 연한 적색 배경·적색 테두리·적색 값으로 표시한다.
- 점수 chip의 근거 이동 기능은 그대로 유지한다.

## 검증

- Team Review 렌더링과 CSS 연결을 dashboard IA 테스트로 확인했다.
