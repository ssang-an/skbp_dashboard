# 08. Filter 3 v1.2 Stage 경계 정정 작업 로그

## 반영 기준

- 투자: Non-small molecule이 `IND-enabling` 이상이며 `IND filed/cleared`, Phase 1 이상을 포함한다.
- Value Up: Small molecule이 확인된 `IND-enabling` 미만 전임상 단계이고, In Vivo O, In Vitro O, ADMET 25 이상을 모두 충족해야 한다.
- 정보원: 구조화된 Dashboard 값 우선, 부족한 값만 Full Scout 및 Partner Materials에서 확인한다. 확인되지 않은 값은 추정하지 않는다.

## 적용 범위

- Filter 3 자동 분류 서버와 기존 Shortlisting 재분류 버전을 v1.2로 갱신했다.
- Dashboard 판단 근거, 상세 페이지 기준 안내, Filter 3 매니페스트 및 스키마 설명을 동일 기준으로 맞췄다.
