# 43. 루브릭 초기화 이력 버전 표시

## 목표

- Tab 1 재평가로 수동 점수가 공식 GPT 점수로 돌아갈 때, 변경 이력에서 사람 수정과 구분한다.

## 규칙

- 저장된 공식 점수의 루브릭 버전과 현재 최신 버전이 다르면: `TR 점수 · 최신 루브릭 vX로 초기화`
- 저장된 공식 점수의 루브릭 버전과 현재 최신 버전이 같으면: `TR 점수 · 기존 루브릭 vX 점수로 초기화`
- 점수의 이전값과 초기화된 공식 점수는 기존처럼 함께 기록한다.

## 검증

- 기존 루브릭 복원과 최신 루브릭 갱신의 audit change method를 회귀 테스트한다.
