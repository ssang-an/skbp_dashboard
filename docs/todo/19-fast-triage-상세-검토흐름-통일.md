# 19. Fast Triage 상세 검토 흐름 통일

## 목적

Fast Triage 상세페이지를 Full Scout 검토 흐름과 연결해, 관리자 점수 수정·최종 의견·변경 이력을 제공하고 각 3개 기준에 팀 메모를 남길 수 있게 한다.

## 작업 범위

1. Fast Triage의 TR·MoA·Data 점수를 관리자만 0–3점으로 수정할 수 있도록 기존 수동 검토 API를 확장하고, 총점은 9점 기준으로 계산·표시한다.
2. 점수와 최종 의견의 수정 이력을 Fast Triage 상세 우측 검토 패널에서 사람이 읽기 쉬운 형식으로 표시한다.
3. 각 기준 카드에 필요할 때만 열리는 포스트잇형 팀 메모 입력란을 추가하고, 기존 Topic Note 저장·권한·감사 이력을 재사용한다.
4. 판단 요약에 관리자 전용 Final comment를 추가한다.
5. 불필요한 `triage_only` 및 내부 Flags 노출을 제거하고, Run Full Scout 표현과 좌측 강조선 등 Fast Triage 특유의 거친 UI를 정리한다.
6. JavaScript 구문 및 핵심 API 회귀 테스트를 수행한다.

## 완료 기준

- Fast Triage 상세에서 관리자 점수 수정과 이력 확인이 가능하다.
- 기준별 팀 메모는 버튼을 누를 때만 입력 영역이 열리고 저장 후 해당 카드에 남는다.
- Final comment는 관리자만 작성·수정할 수 있으며 이력이 남는다.
- 사용자에게 `triage_only`와 Flags가 노출되지 않는다.
