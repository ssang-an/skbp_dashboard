# 23. Tab0 Quick Guide 지침 복사 안내 정리 (완료)

## 반영 내용

- 안내 문구를 `조사 대기 항목 복수 선택 → GPT 지침 복사 → 후보 목록 자동 포함` 순서로 간결하게 정리했다.
- 상태·GPT·지침을 각각 별도 pill로 표시하던 구성을 제거하고, 복사 아이콘과 `GPT 지침 복사` 라벨을 갖는 하나의 Quick Guide action pill로 통일했다.
- Quick Guide action pill을 누르면 실제 Tab0 `GPT 지침 복사` 버튼이 실행되도록 연결했다.

## 검증

- JavaScript 구문 검사와 변경분 공백 검사를 통과했다.
