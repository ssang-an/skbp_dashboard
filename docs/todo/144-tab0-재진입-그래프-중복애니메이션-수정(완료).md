# Tab 0 재진입 그래프 중복 애니메이션 수정

## 목표

다른 탭에서 Tab 0 진척 현황으로 돌아올 때, 기존 DOT 그래프가 잠깐 표시된 뒤 다시 왼쪽에서 시작하는 애니메이션이 중복 실행되지 않도록 한다.

## 작업

- [x] 캐시된 진척 데이터를 즉시 한 번만 렌더링하여 DOT가 곧바로 좌측에서 진입하도록 한다.
- [x] 백그라운드 새로고침은 실제 데이터가 달라진 경우에만 다시 렌더링한다.
- [x] 오래된 비동기 응답이 최신 그래프를 다시 덮어쓰지 않도록 요청 순서를 보호한다.

# Tab 0 재진입 그래프 중복 애니메이션 수정 작업로그

- 탭 재진입 시 캐시 그래프를 먼저 한 번만 재구성하고, 동일한 진행 현황 응답은 화면을 다시 그리지 않도록 변경했다.
