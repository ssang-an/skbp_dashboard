# 113. Tab 0 단계별 순차 노드 등장 애니메이션

## 목표

- Tab 0 Summary Dashboard의 단계별 node cloud가 Listing부터 우측 단계 순서로 자연스럽게 나타난다.
- 대량 Listing node도 렌더링 부담 없이 애니메이션을 제공한다.

## 작업

- [x] 각 단계 canvas에 Listing → Fast Triage → Full Scout → Shortlisting 순차 delay를 부여했다.
- [x] opacity·transform만 사용하는 일회성 CSS animation으로 성능 부담을 제한했다.
- [x] 회귀 테스트·작업 로그·changelog를 갱신했다.
