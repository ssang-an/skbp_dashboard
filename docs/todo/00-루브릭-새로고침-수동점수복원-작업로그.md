# Tab2 루브릭 새로고침 수동 점수 복원 작업 로그

- 완료일: 2026-08-19
- 범위: Full Scout 관리 열의 루브릭 새로고침 동작

## 확인된 원인

- Dashboard의 사람 점수 수정은 `meta.human_review.overrides`에 보관되며, 화면은 이 값을 공식 `scoring`보다 우선 표시한다.
- 기존 새로고침 API는 AI가 점수 변경이 없다고 반환한 경우 조기 종료하여 해당 override를 남겼다.

## 적용 내용

- 최신 루브릭으로 이미 검토된 공식 GPT 점수가 있으면 AI 호출 없이 수동 criterion/Total Score override를 해제한다.
- 루브릭 재평가가 수행됐지만 점수 변경이 없는 경우에도 동일하게 공식 점수로 복원한다.
- 기존 수동 값과 복원된 공식 값은 `human_review.history` 및 edit history에 남긴다.
- 수동 점수가 존재하는 행은 새로고침 안내문에서 복원 동작을 설명하고, API 응답 후 테이블을 다시 렌더링한다.
