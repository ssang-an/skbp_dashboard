# 20. 유사 파이프라인 검토 모달 안내 정리 (완료)

## 완료 내용

- 검토 모달 제목을 `유사한 기존 Pipeline이 N건 있습니다.`로 변경했다.
- 안내문을 `비교 후 각 항목별로 덮어쓰기를 선택한 뒤 선택 적용하면 반영됩니다.` 흐름으로 정리했다.
- 안내문 속 덮어쓰기와 선택 적용을 실제 액션 버튼과 같은 색·둥근 형태·아이콘의 pill로 표시했다.
- 모달 상단의 `기존 조사 결과 확인` 보조 문구를 제거했다.

## 검증

- `node --check src/app.js`
- `git diff --check`
