# 84. 테이블 표기와 Website 아이콘 통일 (완료)

## 완료 결과

- Tab 0 Target은 Tab 1·2와 같은 강조·여러 줄 표시 규칙을 적용한다.
- Tab 0 Evaluation Progress는 Tab 1·2 점수 그룹과 같은 accent 색상·글꼴·굵기로 표시한다.
- Tab 1·2의 점수 그룹명은 모두 `Fast Triage`로 표시한다.
- Tab 0 Website는 등록 시 체크 pill로 표시하며, Tab 1·2는 재평가·관리 아이콘 오른쪽에 외부 링크 pill을 항상 표시한다. 미등록 아이콘은 점선으로 구분되고 관리자 더블클릭으로 URL을 등록할 수 있다.

## 검증

- JavaScript 문법 검사, Python 컴파일 및 관련 Listing 회귀 테스트 통과.
