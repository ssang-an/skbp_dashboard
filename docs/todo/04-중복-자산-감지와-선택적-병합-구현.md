# 04. 중복 자산 감지와 선택적 병합 구현

## 목적

승인된 03 정책에 따라 업로드 전 유사 자산을 안내하고, 사용자가 새 레코드 생성·스킵·기존 레코드 병합을 선택하도록 구현한다.

## 작업

- 결정론적 정규화와 유사도 후보 API를 구현하고, 응답에 매칭 근거와 신뢰 수준을 포함한다.
- 기존 대시보드 모달의 색상·간격·버튼 규칙을 재사용한 2단계 선택 UI를 만든다.
- Tab 0·1의 다수 후보는 스크롤 가능한 asset/company/stage 목록으로 표시한다.
- 병합은 승인된 필드만 변경하고, 전문 보고서·첨부·메모·Team Review Workspace는 지정 정책대로 보존한다.
- 유사 이름은 기존 UI 색상 체계와 맞는 강조 표시를 제공한다.
- 정규화, 후보 탐지, 각 선택 결과, 중복 상세 페이지 방지에 대한 테스트를 추가한다.

## 완료 기준

- 유사 후보가 있을 때 업로드 사용자가 명시적으로 선택한다.
- 스킵은 기존 데이터를 변경하지 않으며, 병합은 선택 범위 외 데이터를 지우지 않는다.
- 실패·취소 시 원자적으로 원상 유지된다.
- 단일 목적 Git 커밋을 남긴다.
