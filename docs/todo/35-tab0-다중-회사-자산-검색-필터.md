# 35. Tab 0 다중 회사·자산 검색 필터

## 목표

- 후보 목록의 회사명·자산명 검색어를 여러 개 선택해 동시에 필터링한다.

## 작업 순서

1. 검색창의 native 지우기(X) 왼쪽에 현재 검색어를 추가하는 `+` 버튼을 둔다.
2. 추가한 검색어를 입력창 오른쪽 pill로 표시하고 각 pill에서 `−`로 개별 해제하게 한다.
3. 선택한 검색어 중 하나와 일치하는 후보를 표시하고, 진행 단계 필터와 함께 적용한다.
4. Reset으로 입력 중 검색어와 모든 pill을 함께 초기화하고 회귀 테스트를 추가한다.
