# 72. Tab 0 Contact 이력 상태 정규화

## 목표

Listing input의 Contact 값을 일관되게 해석해, 실제 연락 이력이 있는 Pipeline만 체크로 표시한다.

## 규칙

1. `O`, 날짜, 이름·이메일·연락 메모 등 비어 있지 않은 실제 텍스트는 Contact 이력 있음으로 처리하고 체크를 표시한다.
2. 빈칸, 정확한 `X`, 하이픈만 있는 `-`·`–`·`—`은 Contact 이력 없음으로 처리하고 `-`를 표시한다.
3. Contact 이력 없음의 `-`는 버튼·tooltip·popover를 만들지 않는다.
4. 저장 시 absence marker는 빈 Contact 값으로 정규화하되, 기존 값은 Tab 0 표시에서 즉시 같은 규칙을 적용한다.

## 완료 기준

- Excel 붙여넣기와 직접 수정 모두 같은 Contact 판정 규칙을 쓴다.
- 날짜·`O`·긴 한국어 메모는 체크로, `X`·`-`·빈칸은 비클릭 `-`로 보인다.
