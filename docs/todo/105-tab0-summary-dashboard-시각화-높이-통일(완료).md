# 105. Tab 0 Summary Dashboard 시각화 높이 통일

## 목표

Tab 0의 단계별 노드 카드 높이를 Fast Triage·Full Scout·Shortlisting Summary Dashboard의 공통 시각화 카드 높이(332px)와 맞춘다.

## 작업 범위

1. Tab 0 단계 카드의 외곽 높이를 332px로 고정한다.
2. 상단 수치 영역은 공통 dashboard header와 같은 64px 높이를 사용한다.
3. 각 G6 캔버스는 남은 카드 높이를 사용하도록 조정한다.

## 완료 기준

- 데스크톱에서 Tab 0의 단계별 시각화 카드가 다른 탭 Summary Dashboard card와 동일한 세로 높이를 가진다.
- 노드 그래프는 남은 높이를 모두 사용하면서 카드 밖으로 넘치지 않는다.
