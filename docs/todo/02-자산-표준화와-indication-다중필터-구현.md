# 02. 자산 표준화와 indication 다중 필터 구현

## 목적

승인된 01의 정책에 따라 복수 indication을 보존하고, 대시보드에서 표시·키워드 정렬·동시 필터가 가능하도록 구현한다.

## 작업

- JSON schema 및 설명 문서를 데이터 모델 변경에 맞춰 함께 수정한다.
- 기존 레코드를 안전하게 읽을 수 있도록 하위 호환 정규화/마이그레이션 경로를 구현한다.
- Tab 1·2·3에 복수 indication의 쉼표 표시, 키워드 포함 정렬/검색, 다중 선택 필터를 추가한다.
- lead indication이 있을 때만 별도로 구분하고, 불명확한 경우 복수 후보를 보존한다.
- 입력 화면 및 GPT 지침에 `UNKNOWN` 남용 방지 안내를 추가한다.
- 실제 JSON 샘플로 기존 단일값·복수값·lead 미정 사례를 검증한다.

## 완료 기준

- 기존 레코드와 신규 복수-indication 레코드가 모두 정상 표시된다.
- 둘 이상의 indication 조건을 동시에 적용·해제할 수 있다.
- 스키마/문서/테스트(또는 재현 절차)가 일치한다.
- 단일 목적 Git 커밋을 남긴다.
