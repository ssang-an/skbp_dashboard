# 51. AI 2차 파싱 대기 문구 정정

## 목적

차단 팝업으로 이미 화면 이동이 제한된 상태에서 중복 안내를 제거하고, 사용자가 현재 작업의 다음 결과를 이해할 수 있는 대기 문구를 제공한다.

## 작업 범위

1. AI 2차 파싱 팝업의 “다른 화면으로 이동할 수 없습니다” 문구를 제거한다.
2. 원문·구조화 데이터 보완 뒤 업로드 준비가 진행 중임을 알리는 간결한 문구로 대체한다.

## 완료 기준

- AI 2차 파싱 팝업에 이동 제한 문구가 표시되지 않는다.
- 상태 문구가 업로드 준비를 위한 대기 안내로 표시된다.
