# Tab 0 필터별 DOT 컬러 인코딩

## 목표

Summary Dashboard 헤더는 중립 스타일로 유지하고, 선택한 Tab 0 필터의 카테고리 값을 워크플로 DOT 색상에만 반영한다.

## 작업

- [x] 헤더·카드 테두리에 적용한 필터 색상 강조를 제거한다.
- [x] 기본 상태에서는 진행 단계별 DOT 색상을 유지한다.
- [x] Country·Modality·Theme·Cluster·Main indication·Stage 필터 선택 시 해당 카테고리 값의 안정적인 색상으로 DOT를 표시한다.
- [x] 여러 필터가 활성화되면 가장 최근 선택한 필터를 색상 기준으로 사용한다.
