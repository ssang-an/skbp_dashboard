# 47. 업로드 바로가기와 성공 후 입력 초기화

## 목적

Tab 1/2 상단 `PIPELINE 업로드` 버튼이 현재 워크플로의 입력 영역으로 확실히 이동하게 하고, 저장 성공 후에는 기존 입력 원문을 비워 저장 완료 결과와 구분한다.

## 작업 범위

1. Tab 1/2 업로드 바로가기 전에 해당 입력 패널을 활성화하고 다음 렌더 프레임에서 스크롤·포커스한다.
2. Fast Triage와 Full Scout 저장 성공 때만 입력란과 탭별 임시 원문을 비운다.
3. 검증 실패·저장 실패·취소 시 입력 원문은 유지한다.
4. Tab 0 후보 목록은 기존 성공 시 초기화 동작을 유지한다.

## 완료 기준

- Tab 1과 Tab 2의 상단 바로가기 버튼이 Data Upload 입력란으로 이동한다.
- 성공 후에는 결과 안내는 남고 입력란만 비워진다.
- 실패 시 재시도할 원문이 남는다.
