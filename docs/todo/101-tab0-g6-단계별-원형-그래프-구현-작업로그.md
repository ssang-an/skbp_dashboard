# Tab 0 G6 단계별 원형 그래프 작업 로그

## 결과

- G6 v5 Canvas를 Tab 0 Workflow Map에 연결했다. 현재 Tab 0 필터 결과를 최고 완료 단계별로 배치하며, 원형 node 크기는 Listing 8px · Fast Triage 10px · Full Scout 13px · Shortlisting 16px이다.
- 각 레인의 색상·건수는 Summary 카드와 같은 진행 흐름을 유지하고, node hover로 Asset·Company·Stage를 확인한다.
- G6 CDN이 로드되지 않거나 렌더링 오류가 발생해도 화면이 비지 않도록 안내 문구를 표시한다.
- 확인: `DashboardInformationArchitectureTests.test_step0_workflow_map_uses_filtered_rows_and_g6_stage_nodes` 통과, `node --check src/app.js` 통과, `git diff --check` 통과. 전체 `tests.test_dashboard_ia`는 기존 UI 계약 불일치 항목들로 실패했으며 이번 변경 범위의 단일 회귀 테스트는 통과했다.
