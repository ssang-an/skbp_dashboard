# Tab 0 G6 단계별 원형 그래프 구현

## 목적

Tab 0 Summary Dashboard의 Workflow Map을 G6 Canvas 그래프로 교체한다. 현재 필터 결과의 Pipeline은 최고 완료 단계 한 곳에만 표시하고, 단계가 진행될수록 원형 node 크기를 키워 진행도를 직관적으로 보여준다.

## 작업 순서

1. G6 v5를 Vanilla JS 페이지에서 로드하고, 라이브러리 미로딩 시에도 화면이 비어 있지 않도록 제한적인 대체 안내를 둔다.
2. Listing · Fast Triage · Full Scout · Shortlisting의 고정 4개 레인에 현재 필터 결과를 배치한다.
3. 단계별 색상과 크기(작은 Listing → 큰 Shortlisting)를 적용하고, hover 시 Asset·Company·Stage를 확인할 수 있게 한다.
4. 필터 변경 시 그래프가 다시 계산되는지와 좁은 화면의 가로 스크롤·reduced-motion 동작을 점검한다.
5. 회귀 테스트, JS 구문 검사, 변경 로그를 남긴다.
