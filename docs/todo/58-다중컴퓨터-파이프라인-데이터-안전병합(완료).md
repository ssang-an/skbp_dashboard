# 58. 다중 컴퓨터 Pipeline 데이터 안전 병합

## 목적

회사 PC의 Git stash와 원격 최신 `json/pipeline-records.json`을 비교하여, 서로 다른 컴퓨터에서 저장된 Pipeline을 누락 없이 통합한다.

## 원칙

- 현재 작업 트리(원격 최신 데이터)를 기준으로 유지한다.
- stash에만 존재하는 stable record ID는 추가한다.
- 동일 ID이면서 내용이 다른 record는 자동 덮어쓰지 않고 차단·보고한다.
- 기본 실행은 dry-run이며, 충돌·중복 ID가 없을 때만 명시적으로 `--write`한다.
- 원본 JSON은 write 전에 로컬 백업한다. Obsidian/wiki는 JSON 병합 확정 후 재생성한다.

## 완료 조건

- Git stash 또는 JSON snapshot을 비교하는 CLI가 있다.
- 추가·동일·충돌·중복 ID를 명확히 출력한다.
- 안전한 union write와 원자적 백업을 회귀 테스트한다.

## 완료

- stash·snapshot 안전 병합 CLI와 회귀 테스트를 구현했다.
- 두 컴퓨터 운영 절차와 회사 PC 실행 명령을 README에 기록했다.
