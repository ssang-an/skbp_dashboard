# 62. Tab 1 재평가 유틸리티 아이콘 통일

## 목적

Fast Triage(Tab 1) 관리 열의 재평가와 Full Scout 지침 복사 버튼을 Tab 2 새로고침과 동일한 SVG 기반 원형 유틸리티 버튼 체계로 통일한다.

## 작업 범위

1. 문자형 재평가 기호를 Tab 2 새로고침과 같은 SVG로 교체한다.
2. 재평가와 복사 버튼에 공통 아이콘 class, 크기, hover 확대 효과를 적용한다.
3. 재평가 처리 중 SVG 회전 상태를 유지한다.

## 완료 기준

- Tab 1 재평가와 복사 버튼이 Tab 2 새로고침과 같은 선형 SVG·원형 버튼 인상을 제공한다.
- 기존 재평가 및 복사 기능은 변경하지 않는다.
