# 109. Tab 0 Listing 밀집과 Shortlisting 강조 조정

## 목표

대량 Listing은 낮은 반발로 촘촘하게 표시하고, 소수 Shortlisting은 더 큰 node와 넓은 간격으로 강조한다.

## 작업 범위

1. Listing의 many-body 반발·collision padding/strength를 낮춘다.
2. Shortlisting node 크기와 반발·충돌 간격을 올린다.
3. 카드 직사각형 boundary와 clipping은 유지한다.

## 완료 기준

- Listing 대량 node가 더 조밀하게 표시된다.
- Shortlisting node가 다른 단계보다 명확히 크고 여유 있게 표시된다.
