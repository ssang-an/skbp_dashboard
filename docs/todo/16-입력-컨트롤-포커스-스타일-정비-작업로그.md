# 16 완료 작업 로그

- Dashboard, detail, Team Review Workspace, modal의 일반 text/date 입력칸·textarea·select에 중립 회색 테두리와 단일 음영 focus를 적용했다.
- 상태 색상을 가진 테이블 편집 select는 의미색 배경을 유지하며, focus는 중립 회색으로 표시한다.
- Data Upload의 GPT 입력칸은 `--data-upload-accent` 기반의 은은한 초록 focus를 유지한다.
- 버튼·탭·헤더·hover 전용 강조는 변경하지 않았다.
- 검증: `node --check src/app.js`, `python -m unittest tests.test_input_focus_ux -v`.
