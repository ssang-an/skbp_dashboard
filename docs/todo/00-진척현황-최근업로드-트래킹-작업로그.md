# 00. 진척 현황 최근 업로드 트래킹 작업 로그

## 반영 내용

- Tab0 진척 현황 요약의 조사 대기·Fast Triage·Full Scout·Shortlisting 숫자 옆에 최근 15일 신규 수를 적색 `▲ +N`으로 표시한다.
- 제목 오른쪽의 `최근 15일 신규 업로드` 안내와 tooltip으로 기간과 계산 기준을 명확히 표시한다.
- 신규 Fast Triage/Full Scout 저장 시 immutable `meta.dashboard_uploaded_at`을 기록한다. Shortlisting은 등록 시각(`focus_management.added_at`), 조사 대기는 후보 등록 시각을 사용한다.
- 기존 레코드는 별도 업로드 시각이 없으므로 보존된 `meta.generated_at`을 legacy fallback으로 사용한다.

## 검증

- Step0 progress API의 각 workflow 최근 15일 집계와 Dashboard 표시 연결을 자동 테스트한다.
