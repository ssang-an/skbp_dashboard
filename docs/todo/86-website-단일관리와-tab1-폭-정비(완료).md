# 86. Website 단일관리와 Tab 1 폭 정비

## 목표

- Website URL의 등록·수정 권한을 Tab 0 Listing으로 한정하고 Tab 1·2는 링크 열기만 제공한다.
- Tab 1·2의 관리 액션 안에서 Website 아이콘을 맨 오른쪽에 배치한다.
- Stage 열의 기본·최소 폭을 줄여 Website 아이콘 추가 후에도 불필요한 가로 스크롤을 줄인다.

## 작업 순서

1. Tab 1·2 Website 버튼의 안내·이벤트에서 주소 수정 경로를 제거한다.
2. 재평가/관리 액션의 아이콘 순서를 새로고침 → 복사 또는 즐겨찾기 → Website로 맞춘다.
3. Stage와 액션 열의 폭을 실제 아이콘 수에 맞게 재조정한다.
4. 구문·회귀 테스트와 문서를 갱신한다.
