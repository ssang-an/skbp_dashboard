# 29. Tab1·2 다중필터 메뉴 표시 복구 (완료)

## 완료 내용

- Tab1·2 필터 드롭다운을 포함한 control panel의 overflow를 필터 메뉴에 한해 visible로 변경했다.
- 메뉴에 레이어 순서를 부여해 패널 밖으로 펼쳐질 때도 테이블 위에 표시되도록 했다.
- 다중선택 동그라미 UI, 선택 상태, 복수 조건 필터 로직은 변경하지 않았다.

## 검증

- `git diff --check`
- 브라우저 자동화 연결이 현재 환경에 없어, DOM 이벤트 흐름과 CSS clipping 경로를 정적 점검했다.
