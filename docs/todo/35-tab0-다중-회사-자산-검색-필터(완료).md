# 35. Tab 0 다중 회사·자산 검색 필터 (완료)

## 완료 내용

- Tab 0 검색창에 `+`를 추가해 입력한 회사명 또는 자산명을 다중 검색 조건으로 저장한다.
- 선택 조건은 검색창 오른쪽 pill로 보이며, pill의 `−`로 조건 하나만 제거할 수 있다.
- 여러 검색 조건은 OR로 적용되어, 회사·자산을 혼합 선택해도 관련 후보가 함께 표시된다.
- 진행 단계 필터는 기존처럼 동시에 적용되고 Reset은 모든 검색 pill을 해제한다.
