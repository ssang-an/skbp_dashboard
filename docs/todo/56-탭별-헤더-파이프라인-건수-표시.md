# 56. 탭별 헤더 파이프라인 건수 표시

## 목표

대시보드 상단 `Dashboard` 오른쪽 상태 영역을 저장 성공 같은 일시 메시지가 아니라, 현재 선택한 Tab의 전체 Pipeline/Asset 로드 건수로 일관되게 표시한다.

## 작업 범위

1. Tab 0 진척 현황, Tab 1 Fast Triage, Tab 2 Full Scout, Tab 3 Shortlisting 각각의 전체 행 수를 계산한다.
2. 탭 전환, 데이터 재로딩, 필터/테이블 재렌더링, 수동 수정 저장 뒤에도 상단 문구를 `총 N건 로드됨`으로 복원한다.
3. 저장 진행·성공 문구는 상단 헤더를 점유하지 않도록 기존 업로드/작업 상태 영역을 유지하고, 실패 안내만 필요한 위치에 남긴다.

## 검증

- Tab 0~3 전환 시 각 탭의 전체 건수가 헤더에 표시되는지 확인한다.
- Tab 1/2 수동 수정 성공 후 `Human review saved` 같은 메시지 대신 해당 탭 건수가 다시 표시되는지 회귀 테스트한다.
