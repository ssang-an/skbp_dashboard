# 처리 중 대기 모달과 실행 취소 작업 로그

## 반영 범위

- 대시보드 새로고침, 최신 루브릭 재평가, Filter 3 재분류, 데이터 저장, 후보 목록 가져오기, AI 2차 파싱에 공통 대기 모달을 적용했다.
- 모달은 작은 모래시계 아이콘, 진행 문구, 실행 취소 버튼을 제공하며 작업 중 다른 대시보드 조작을 막는다.
- 실행 취소는 진행 중인 브라우저 요청을 중단한다. 서버 저장이 이미 시작된 시점에는 결과가 저장될 수 있음을 모달에서 안내한다.
- All Pipelines Agent 채팅은 기존처럼 대기 모달을 사용하지 않는다.

## 검증

- JavaScript 문법 검사와 대시보드 UI 계약 테스트로 모달 마크업, 취소 연결, AI 채팅 제외 여부를 확인했다.
