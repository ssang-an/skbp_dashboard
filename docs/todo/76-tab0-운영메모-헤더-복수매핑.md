# 76. Tab 0 운영 메모 Header 복수 매핑

## 범위

- Excel의 `HQ Location`을 Country로 인식한다.
- `Comment`, `Priority`, `Reason for Priority`, `Next Step`을 Comment로 함께 보존한다.
- `Meeting History`, `Contact History`, `Contact`을 Contact으로 함께 보존한다.
- 같은 목적의 열이 복수일 때 마지막 값으로 덮어쓰지 않고 행별 줄바꿈으로 병합한다.

## 검증

- header 매핑 규칙과 JavaScript 문법을 점검한다.
