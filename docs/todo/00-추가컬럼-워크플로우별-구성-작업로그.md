# 00. 추가 컬럼 워크플로우별 구성 작업 로그

## 반영 내용

- Tab2 Full Scout의 추가 컬럼 설정에서 JSON 경로를 보조 문구로 노출하지 않는다.
- Full Scout에는 MoA, 회사·플랫폼, 경쟁, 권고, 출처·불확실성처럼 심층 조사 결과에 맞는 항목만 제공한다.
- Tab1 Fast Triage에는 기본 표에 이미 있는 Modality·Indication을 중복 제공하지 않고, 활성 상태·검증 출처 수·Triage 근거·Full Scout에 필요한 추가 근거 등 Fast Triage 계약의 항목만 제공한다.
- 활성 상태와 검증 출처 수는 표·Excel 내보내기에서 읽기 쉬운 값으로 표시한다.

## 검증

- workflow별 컬럼 정의와 JSON 경로 미노출 여부를 확인하는 Dashboard UI 회귀 테스트를 추가한다.
