# 36. Tab 1/2 다중 필터 클릭 메뉴 복구

## 목표

Tab 1 Fast Triage와 Tab 2 Full Scout의 Country, Modality, Theme, Cluster, Main indication, Stage, Filter 1/2 드롭다운을 클릭하면 다중 선택 메뉴가 열리도록 복구한다.

## 작업 범위

1. 다중 필터 클릭 이벤트가 Tab 0 컨트롤에만 연결되지 않도록 모든 컨트롤 행에 등록한다.
2. 메뉴의 `hidden` 상태와 `aria-expanded` 상태를 함께 갱신한다.
3. 열린 메뉴가 테이블 등 다른 화면 요소 뒤에 가려지지 않도록 쌓임 순서를 보완한다.
4. 브라우저 캐시를 갱신하고, 회귀 테스트로 이벤트 연결과 메뉴 상태 전환을 확인한다.

## 완료 기준

- Tab 1/2에서 각 필터 trigger 클릭 시 옵션 메뉴가 보인다.
- 원형 선택 표시로 복수 조건을 선택하고, 전체 옵션으로 해제할 수 있다.
- 메뉴 밖 클릭 또는 Escape로 메뉴가 닫힌다.
