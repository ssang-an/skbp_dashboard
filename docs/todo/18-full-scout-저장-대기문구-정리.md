# 18. Full Scout 저장 대기 문구 정리

## 목적

Full Scout GPT 답변 저장 중 표시되는 차단 팝업에서 이미 화면이 비활성화되는 상태와 중복되는 이동 제한 안내를 제거한다.

## 작업 범위

1. Full Scout 저장 작업의 상태 문구를 저장 완료까지 기다려 달라는 안내로 교체한다.
2. 팝업의 제목과 저장·대시보드 갱신 설명은 유지한다.
3. JavaScript 구문 검사를 수행한다.

## 완료 기준

- 저장 팝업에 "다른 화면으로 이동할 수 없습니다" 문구가 표시되지 않는다.
- 저장 진행 중에는 간결한 대기 안내만 표시된다.
