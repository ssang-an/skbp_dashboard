# 41. Fast Triage 최종 코멘트와 코멘트 삭제 이력

## 목표

- UNVERIFIED 설명을 한 줄로 정리한다.
- 우측 Quick scan에서 변경 이력 바로 위에 최종 코멘트 입력 기능을 제공한다.
- 기준별 코멘트와 최종 코멘트는 작성한 관리자만 삭제할 수 있고, 삭제도 변경 이력에 남긴다.

## 작업

1. 최종 코멘트 UI를 우측 Quick scan으로 이동한다.
2. 작성자 관리자에게만 보이는 `×` 삭제 버튼과 서버 권한 검사를 추가한다.
3. 기준별 코멘트 삭제 버튼과 삭제 이력 라벨을 추가한다.
4. 기존 GPT 원문과 rubric 점수는 변경하지 않는다.

## 검증

- Fast Triage manual-review API의 최종 코멘트 작성·삭제 권한 및 이력 동작을 테스트한다.
- JS 문법 검사를 실행한다.
