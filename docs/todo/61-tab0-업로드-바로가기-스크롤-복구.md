# 61. Tab 0 업로드 바로가기 스크롤 복구

## 목적

Tab 0(진척 현황)에서 상단 `Pipeline Upload`를 누르면 후보 목록 Upload 입력란으로 즉시 이동하게 한다.

## 작업 범위

1. 현재 활성 화면이 Tab 0인지 감지한다.
2. Tab 0에서는 `step0UploadPanel`과 `step0PasteInput`으로 이동하고, Tab 1·2는 기존 데이터 입력란으로 유지한다.
3. 고정 헤더에 가려지지 않도록 문서 스크롤 위치를 명시적으로 보정한다.
4. 캐시 버전을 갱신하고 회귀 테스트를 추가한다.

## 완료 기준

- Tab 0 바로가기 클릭 시 후보 목록 Upload 입력란이 화면에 보이고 입력칸에 포커스가 간다.
- Tab 1·2 바로가기 동작은 유지된다.
