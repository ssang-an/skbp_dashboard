# 84. 테이블 표기와 Website 아이콘 통일

## 목표

- Tab 0 Target 표시를 Tab 1·2와 같은 강조 규칙으로 맞춘다.
- Tab 0 `Evaluation Progress` 그룹 헤더를 Tab 1·2 점수 그룹 헤더와 같은 글꼴·색상·강조로 통일한다.
- Tab 1의 `Fast Triage Core`, Tab 2의 `Triage Core`를 모두 `Fast Triage`로 단순화한다.
- Website는 Tab 0에서 체크 pill, Tab 1·2에서는 새로고침과 동일 계열의 외부 링크 icon pill로 표시한다.

## 작업 순서

1. 테이블 헤더와 Target 텍스트의 클래스·스타일을 공통 규칙으로 정리한다.
2. 워크플로별 헤더 문구를 정정한다.
3. Website 표시와 메타데이터 회귀 테스트를 보강한다.

## 비범위

- Website URL 저장 규칙, 점수, 루브릭 및 Pipeline 원문 데이터는 변경하지 않는다.
