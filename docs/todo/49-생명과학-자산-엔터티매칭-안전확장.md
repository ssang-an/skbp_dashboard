# 49. 생명과학 자산 엔터티 매칭 안전 확장

## 목적

덮어쓰기 후보 탐색을 단순 문자열 유사도가 아닌 바이오 파이프라인 자산의 명명 형태에 맞춰 안전하게 보완한다.

## 작업 범위

1. 개발 코드는 구분자·선행 0을 무시하되, 구조·숫자·접미어가 다르면 후보에서 제외한다.
2. 코드 접두어 누락 또는 같은 숫자 코어·다른 접두어는 같은 회사에서만 검토 후보로 표시한다.
3. 서술형 자산명은 같은 회사 안에서만 동일·핵심 의미 토큰을 비교한다.
4. 단일 제품명·INN은 정확한 정규화 일치만 허용하고, 제형·괄호 변형은 자동 동일시하지 않는다.
5. 프런트엔드 후보 탐색과 서버의 확정 덮어쓰기 검증 규칙을 일치시키고 회귀 테스트를 추가한다.

## 완료 기준

- 코드형 별도 자산이 작은 철자 차이만으로 후보에 나타나지 않는다.
- 같은 회사의 서술형 명칭 변형은 사용자 검토 후보로 나타난다.
- 다른 회사의 유사 서술형 자산명은 후보에 나타나지 않는다.
