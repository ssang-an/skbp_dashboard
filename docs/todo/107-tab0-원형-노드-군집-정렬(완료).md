# 107. Tab 0 원형 노드 군집 정렬

## 목표

각 Tab 0 단계의 node cloud가 가로로 길게 퍼지지 않고, 카드 중앙에서 원형에 가까운 군집으로 계속 움직이게 한다.

## 작업 범위

1. G6 캔버스의 실제 렌더 영역을 카드 내 최대 정사각형으로 제한한다.
2. 정사각형 캔버스를 그래프 영역의 정중앙에 배치한다.
3. force layout의 가로·세로 크기를 동일하게 전달한다.
4. Listing 대량 node의 카드 내부 표시 계약을 유지한다.

## 완료 기준

- 데스크톱에서 모든 단계 graph가 동일한 원형에 가까운 node cloud로 보인다.
- 그래프는 카드 내부 중앙에 있고, 카드 외부로 넘치지 않는다.
