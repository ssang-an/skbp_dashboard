# 64. Shortlisting 우선·보류 상태 별표 (완료)

- Tab 2 별표를 `미등록 → 우선 검토(노란색) → Stationary(강한 회색) → 미등록` 순환으로 구현했다.
- Stationary는 Shortlisting에 유지되며, 즉시 도입/파트너십이 어려워 모니터링하는 상태를 뜻한다.
- 별표 hover와 접근성 문구에 상태·다음 동작을 표시하고, 상태 변경은 `meta.focus_management.tracking_status` 및 변경 이력에 남긴다.
- OI Partnership 분류, 점수, GPT 원문은 수정하지 않는다.
