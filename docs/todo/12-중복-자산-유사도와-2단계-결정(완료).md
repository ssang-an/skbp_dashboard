# 12. 중복 자산 유사도와 2단계 결정

## 완료 내용

- 동일 workflow·company alias 안에서 normalized asset의 edit-distance 12% 이내 후보를 탐지한다.
- 후보 selector와 목록에 `동일 표기 정규화` 또는 `유사 자산명` 근거를 함께 표시한다.
- 서버도 같은 workflow/company 및 bounded similarity를 재검증하므로 UI에서 선택하지 않은 임의 record를 덮어쓸 수 없다.
- 사용자는 기존 target 적용 또는 신규 추가를 명시적으로 선택하며, 기존 target을 적용할 때만 metadata preservation/audit snapshot이 작동한다.
