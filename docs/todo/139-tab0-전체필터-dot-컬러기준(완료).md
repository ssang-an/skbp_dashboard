# Tab 0 전체 필터 DOT 컬러 기준

## 목표

Tab 0의 Country·Modality·Theme·Cluster·Main indication `전체`는 행을 제한하지 않으면서 해당 카테고리별 DOT 색상을 표시하고, Stage/진행 단계 `전체`는 기본 단계 색상으로 복귀한다.

## 작업

- [x] 비진행 단계 카테고리의 `전체`를 DOT 색상 기준 선택으로 기록한다.
- [x] Modality `전체`에서도 각 modality의 안정적 색상으로 DOT를 표시한다.
- [x] Stage/진행 단계 `전체`는 색상 기준을 해제해 기본 workflow 색상으로 돌아가게 한다.
