# 66. Tab 0 조사값 우선 표시와 요약 필터 (완료)

- Tab 0의 상세 표시값은 Full Scout가 있으면 Full Scout, 없으면 Fast Triage, 둘 다 없으면 Listing 입력값 순으로 읽기 전용 표시하며, Full Scout의 빈 필드는 Fast Triage의 확인값으로 보완한다.
- Summary 카드 네 개를 진행 단계 다중 필터에 연결했고, 카드·필터 버튼의 활성 상태를 동기화했다.
- 카드 hover는 해당 결과 범위와 이후 단계 완료 항목 포함 여부를 안내한다.
- 이번 변경은 Tab 0 표시·필터만 다루며 조사 레코드의 공식 값·점수·루브릭을 수정하지 않는다.
