# 23. Tab0 Quick Guide 지침 복사 안내 정리

## 목표

- Tab0 Quick Guide의 조사 대기·GPT 지침 복사 안내를 자연스러운 문장으로 고친다.
- 문장 안에 흩어진 상태/GPT pill을 제거하고, Tab1·2 Quick Guide와 같은 하나의 아이콘 action pill로 정리한다.

## 작업 순서

1. 안내 문구를 복수 선택 → 지침 복사 → 후보 목록 자동 포함 흐름으로 간결하게 바꾼다.
2. 복사 아이콘과 `GPT 지침 복사` 라벨을 가진 Quick Guide action pill을 기존 디자인 체계로 렌더링한다.
3. 해당 pill을 누르면 실제 Tab0 지침 복사 버튼을 실행하도록 연결하고 검증한다.
