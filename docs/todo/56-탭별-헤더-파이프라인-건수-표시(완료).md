# 56. 탭별 헤더 파이프라인 건수 표시 (완료)

## 완료 내용

- 상단 `Dashboard` 오른쪽 상태 영역을 현재 탭 전체 행 수인 `총 N건 로드됨`으로 통일했다.
- Tab 0은 진척 현황의 Asset 행 수, Tab 1·2는 각 workflow의 Asset 수, Tab 3은 Shortlisting 행 수를 표시한다.
- 필터 적용, 탭 전환, 수동 점수/필드 저장, 재평가·재분류·내보내기·지침 복사 후에도 저장 성공 문구 대신 건수 표기로 복원한다.
- 브라우저가 수정된 스크립트를 즉시 받도록 dashboard JavaScript 버전 쿼리를 갱신했다.

## 검증

- `node --check src/app.js`
- `python -m unittest tests.test_header_record_count -v`
