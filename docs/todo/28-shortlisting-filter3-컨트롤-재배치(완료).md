# 28. Shortlisting Filter 3 컨트롤 재배치 (완료)

## 완료 내용

- 자동 기준 재분류 선택지를 Filter 3 드롭다운에서 제거했다. 자동 분류 복귀는 `v1.4 기준 갱신` 버튼만 사용한다.
- Filter 3 메타데이터·기준 갱신 버튼은 왼쪽, 작은 분류 드롭다운은 같은 상단 행 오른쪽으로 배치했다.
- 판단근거 입력란은 기본 두 줄(56px)을 표시하며, 더 긴 내용만 내부 스크롤된다.
- 작은 화면에서는 상단 행이 자연스럽게 줄바꿈된다.
