# SKBP Dashboard 작업 로드맵

## 운영 규칙

- 이 폴더의 미완료 작업 파일을 **한 번에 하나만** 열어 구현한다.
- 해당 파일의 완료 기준과 검증을 모두 만족한 뒤, 실행 내용을 기록한 `NN-제목(완료).md`로 이름을 변경한다.
- 다음 번호의 파일은 이전 작업 완료 및 커밋 후에만 연다.
- 코드·설정·문서가 바뀐 작업은 작업별로 독립적인 Git 커밋을 남기고, `docs/changelog/2026/2026-08-12.md`에 사실만 짧게 기록한다.
- 생성물인 `obsidian/`, `skbp_pipeline_wiki/`는 직접 편집하지 않는다. 필요한 경우 원본 JSON 또는 exporter를 고친 뒤 재생성한다.

## 승인 지점

다음 항목은 구현 전에 사용자의 명시적 결정을 받아야 한다.

1. 01: indication 표준화 규칙과 다중 필터의 정확한 동작.
2. 03: 유사 자산 판정 임계값 및 ‘새로 생성/기존 항목에 병합’의 최종 병합 정책.

그 외 항목은 각 작업 파일의 완료 기준을 충족하는 범위에서 순차 구현한다.
