# 49. 생명과학 자산 엔터티 매칭 안전 확장 (완료)

## 반영 내용

- 105개 현재 파이프라인 자산을 점검한 결과, 75개가 코드형이고 28개가 서술형·기타 명칭임을 확인했다.
- 코드형은 구성요소 순서·숫자·접미어를 보존해 비교한다. 구분자와 선행 0만 다른 경우만 동일 후보가 된다.
- 같은 회사에서 코드 접두어가 빠졌거나 숫자 코어만 같은 경우는 자동 동일시하지 않고 검토 후보로만 다룬다.
- 서술형은 동일 회사 범위에서 핵심 토큰을 비교하며, 다른 회사의 유사한 질환·프로그램 문구는 후보에서 제외한다.
- 제품명·INN은 정규화 정확 일치만 후보로 처리하며, 괄호 안 제형·경로 표기는 별도 변형으로 보존한다.
- 서버 확정 단계도 원래 자산명·회사명을 사용해 같은 규칙을 다시 검증한다.

## 검증

- 코드 서식·선행 0·복합 코드·숫자 충돌·접미어 충돌·접두어 누락·서술형 회사 범위·INN·제형 변형 회귀 테스트
