# 57. Tab 1 업로드 바로가기 복구와 당일 변경 점검

## 목표

Fast Triage(Tab 1) 상단 `PIPELINE 업로드` 버튼이 항상 현재 탭의 Data Upload 입력란으로 이동하도록 보완하고, 오늘 반영한 화면·업로드·수동편집 변경이 현재 코드에 유지되는지 점검한다.

## 작업 범위

1. 버튼 클릭 시점에 업로드 panel과 입력란을 다시 찾아 Tab 1 가이드/입력란을 보이게 만든 뒤 스크롤한다.
2. 렌더링 상태나 캐시된 DOM 참조에 영향을 받지 않도록 입력란 포커스와 강조 효과를 같은 대상에 적용한다.
3. Fast Triage 수동 편집, 다중 필터, AI 재파싱 오류 안내, 헤더 건수 표시, 업로드 바로가기 관련 회귀 정적 검증을 실행한다.
4. 오늘의 committed 변경과 현재 작업 트리의 미커밋 파일을 분리해, generated vault와 사용자 데이터는 수정하지 않는다.

## 검증

- JavaScript 구문 점검
- 업로드 바로가기 이벤트/대상 정적 회귀 테스트
- Fast Triage 수동 편집·헤더 건수·입력 계약 관련 회귀 테스트
