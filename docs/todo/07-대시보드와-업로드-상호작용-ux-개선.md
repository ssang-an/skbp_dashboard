# 07. 대시보드와 업로드 상호작용 UX 개선

## 목적

요청된 단순 UI 개선을 기존 디자인 시스템에 맞춰 적용한다.

## 작업

- 우측 Summary Dashboard 안에서 Priority Pipeline과 Follow-up Action만 독립 스크롤되고 최대 10개 항목이 보이게 한다.
- 헤더의 Tab 0 건수 라벨을 실제 전체/진척 현황 기준으로 바로잡고, Tab 1·2 Pipeline Table과 용어·폰트 스타일을 통일한다.
- 업로드/처리 중에는 진행 중 모달 또는 인라인 상태를 유지하고 중복 모달이 겹치지 않게 한다.
- Team Review Workspace 파일 첨부 중 버튼과 목록 아이콘을 상태에 맞게 표시한다.
- 안내·복사 성공·업로드 성공 등 피드백을 일관된 pill/toast로 정리한다.
- 키보드 포커스, 긴 목록 스크롤, 작은 화면에서의 모달/테이블 사용성을 점검한다.

## 완료 기준

- 우측 패널 전체가 아니라 지정 목록만 스크롤된다.
- 각 비동기 동작의 진행·성공·실패 상태가 시각적으로 구분된다.
- 기존 모달 스타일을 벗어나는 새 디자인 언어를 만들지 않는다.
- 단일 목적 Git 커밋을 남긴다.
