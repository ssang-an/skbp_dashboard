# 48. 코드형 자산 유사 후보 숫자 식별자 보호

## 목적

덮어쓰기 검토에서 표기만 다른 동일 코드(`AR1001`, `AR-1001`, `AR01001`)는 후보로 유지하고, 숫자 식별자가 다른 별도 자산(`AR1001`/`AR1002`, `AS-301`/`AS-401`)은 유사 후보에서 제외한다.

## 작업 범위

1. 프런트엔드 후보 탐색에 코드형 자산의 숫자 식별자 비교를 추가한다.
2. 서버의 확정 덮어쓰기 검증에도 같은 규칙을 적용한다.
3. 표기 변형 허용과 숫자 상이 차단 회귀 테스트를 추가한다.

## 완료 기준

- 하이픈·선행 0만 다른 동일 자산은 덮어쓰기 후보로 계속 표시된다.
- 코드 숫자가 다른 자산은 회사가 같아도 유사 후보로 표시되지 않는다.
