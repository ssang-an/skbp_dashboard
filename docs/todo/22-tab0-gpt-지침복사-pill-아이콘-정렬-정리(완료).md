# 22. Tab0 GPT 지침 복사 pill 아이콘·명도 정리 (완료)

## 반영 내용

- Tab0 `GPT 지침 복사` pill의 순서를 `복사 아이콘 → GPT → 지침 복사`로 변경했다.
- 버튼·GPT chip·hover 색상을 기존 slate-blue 계열의 더 밝고 부드러운 톤으로 조정했다.
- Excel export와 같은 compact pill 밀도를 유지하면서 복사 기능의 시각적 시작점을 아이콘으로 통일했다.

## 검증

- `index.html` 구조와 `src/styles.css` 선택자를 확인했다.
- JavaScript 문법 검사 및 whitespace 검사를 통과했다.
