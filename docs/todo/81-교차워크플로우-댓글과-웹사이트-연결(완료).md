# 81. 교차 워크플로우 댓글과 Website 연결 (완료)

## 완료 내용

- Tab 0 Listing Comment는 Tab 1·2의 운영 댓글로 `Tab 0` 작성자 표시와 함께 동기화된다.
- Fast Triage의 사람이 작성한 Final Comment와 기준별 의견은 동일 파이프라인 Full Scout의 Team Review Workspace에 `Fast Triage · 항목명` 출처로 한 번만 누적된다.
- AI 생성 정성평가 답변은 이관 및 Tab 0 Comment 피드에서 제외된다.
- 관리자 삭제한 이관 댓글은 이후 같은 리포트를 다시 저장해도 복원되지 않는다.
- Website는 동일 identity의 Tab 0·1·2에서 공통으로 사용하며, 링크 아이콘 한 번 클릭은 열기, 관리자 더블 클릭은 주소 수정이다.
