# 59. Stash 필드 단위 3-way 병합

## 목적

회사 PC stash와 원격 최신 JSON에서 같은 Pipeline ID의 서로 다른 변경을 record 전체 충돌로 처리하지 않고, 공통 Git 기준을 이용해 비중첩 필드 변경을 자동 결합한다.

## 원칙

- Git stash의 첫 parent를 공통 기준으로 사용한다.
- 한쪽만 바꾼 필드는 보존한다.
- 양쪽이 같은 필드를 서로 다르게 바꾼 경우만 차단한다.
- 배열은 순서·의미 보존을 위해 원자 단위로 취급한다.

## 완료 조건

- 자동 결합 수와 실제 field-path 충돌을 report에 남긴다.
- 비중첩 변경 자동 결합 및 같은 필드 충돌 차단 테스트가 있다.
