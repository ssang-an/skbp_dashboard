# Work Log — 2026-11-07

## Changes

- `Dockerfile.spcs`, `Dockerfile.spcs.dockerignore`: added a Snowpark Container Services image (python:3.11-slim, LibreOffice, Nanum fonts). It excludes `.env*`, `.git`, `.venv`, agent folders, and `snowflake/`, so secrets never enter the image.
- `spcs/bootstrap.py`, `spcs/docker-entrypoint.sh`: added startup on the block volume `/app-state/app`. Code syncs on every start and stale files are pruned through `.code_manifest.json`. Data paths (`json/*`, `data`, `attachments`, wiki, `obsidian`, instruction warnings) are seeded once via `.seed-staging` + `.seed_complete.json`, are safe to retry, and are never overwritten. Uvicorn runs with 1 worker.
- `snowflake/01_setup.sql`, `01b_secrets.sql`, `02_admin_request.sql`, `03_create_service.sql`, `04_operations.sql`, `spec.yaml`, `DEPLOY.md`: added the full SPCS deployment set: image repo, network rule, Secret-based keys, admin request (compute pool, EAI, bind), and service creation. Updates use `ALTER SERVICE`, backups/restores use snapshots, and no step drops the service.
- `snowflake/spec.quickstart.yaml`, `snowflake/03q_quickstart_service.sql`: added a quick-start service on `SYSTEM_COMPUTE_POOL_CPU` with a public endpoint, a 10Gi block volume, `LLM_PROVIDER=cortex` (claude-sonnet-4-6), `QUERY_WAREHOUSE=WH_BETATEST`, and no external access. The SMTP reminder, PDF parser fallback, and paid OCR are off.
- `llm_client.py` (new): added the Cortex/OpenRouter transport. It translates payloads (`max_completion_tokens`, removes OpenRouter-only fields, simplifies the json_schema, maps the model) and authenticates with the SPCS session token. Streamed SSE chunks without choices are filtered out, and a 401/403 falls back to SQL `AI_COMPLETE`. OpenRouter is still the default when `LLM_PROVIDER` is unset.
- `main.py`: `post_openrouter` now delegates to `llm_client.post_chat`. The 12 `OPENROUTER_API_KEY` lookups now go through `llm_client.credential()`.
- `document_pipeline.py`: the Filter3 judgment call now goes through `llm_client.post_chat`. In Cortex mode, capability detection is adjusted and OpenRouter PDF parsing is disabled.
- `tests/test_llm_client.py` (new): added 9 tests for the transport (default path, payload translation, headers, SSE filtering, SQL fallback, model validation). All pass. The full test suite has 58 failures both before and after this change (0 new).
- `snowflake/DEPLOY.md`: added `llm_client.py`, `main.py`, `document_pipeline.py`, and `tests/test_llm_client.py` to the 3-1 download table.
