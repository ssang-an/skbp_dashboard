# 2026-08-21

## Changes

- Added a dry-run-first pipeline-record reconciliation tool that compares Git stashes or copied JSON snapshots with the current source data, preserves current records, adds only stash-exclusive record IDs, and blocks same-ID content conflicts before writing.
- Documented the two-computer commit/push/pull workflow and the safe stash reconciliation commands, including automatic JSON backup and derived-vault regeneration after a verified merge.
- Improved stash reconciliation with record-level three-way merging: non-overlapping current/stash field updates merge automatically, while only overlapping field paths remain blocked for review.
- Added an explicit approved-metadata reconciliation mode that keeps the current report/scoring primary, unions company-PC attachments and audit histories, and selects later related timestamps; local reconciliation backups are now ignored by Git.
- Fixed reconciliation of fields deleted on one branch so the internal missing-value marker can never enter a JSON record or interrupt a metadata-policy dry run.
