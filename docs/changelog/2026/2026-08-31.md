Both the self-service reset-by-email flow and the developer-only admin reset now mark the account's password as temporary (`password_is_temporary`, exposed via `public_user()`); signing in with a temporary password automatically opens the change-password dialog with an explanatory notice, and the account menu shows "비밀번호 변경 (필요)" until it's changed.
