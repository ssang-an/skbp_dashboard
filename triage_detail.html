GPT 지침 1 — Fast Triage · v3.3 기준

지침 1은 여러 후보 중 지침 2 Full Scout로 넘길 대상을 빠르게 고르는 1차 screening입니다. Target Relevance, MoA Validity, Data Maturity를 예비 평가하고 SELECT, REJECT, UNVERIFIED로 분류합니다.

SELECT

Full Scout 심층 검토 대상입니다. 최종 BD recommendation을 의미하지 않습니다.

  • Asset identity 확인
  • Active asset
  • TR 2점 이상
  • MoA 또는 Data 중 하나 이상 2점 이상

REJECT

현재 공개 근거 및 개발 상태 기준, Full Scout 우선순위가 충분하지 않습니다.

  • Asset identity는 확인됐으나 SELECT 기준 미충족
  • MoA 또는 Data 근거가 Full Scout 우선순위를 뒷받침하지 못함
  • Inactive, discontinued 또는 명확한 hard blocker가 있는 경우

UNVERIFIED

공개 자료에서 해당 후보를 특정 biotech/pharma pipeline asset으로 확인하지 못했습니다.

  • Asset명 또는 compound code를 실제 의약품 개발 프로그램으로 확인할 수 없음
  • 검색 결과가 비의약품, 동명 코드 또는 불명확한 약어와 혼재함
  • 공식 pipeline page, clinical trial registry 또는 publication 등 identity 확인 source가 필요함

Fast Triage Parameter Guide

세 항목의 평가 범위

1. Target Relevance

SKBP 우선 관심 적응증 및 R&D Theme과 그 하위 Cluster의 적합성을 평가합니다.

  • SKBP 우선 관심 적응증Alzheimer's disease, Parkinson's disease, Amyotrophic lateral sclerosis / motor neuron disease, Multiple sclerosis / neuroinflammatory disease, Neuropathic pain, Epilepsy / seizure disorders
  • E/I BalanceIon Channel, Inhibitory Tone, Synaptic Transmission, Chloride Homeostasis, Network Modulation
  • NeuroimmuneGlial homeostasis, CNS injury immune response, Cytokine neuromodulation, disease immune modulation

2. MoA Validity

작용기전이 얼마나 구체적으로 정의되어 있고, 이를 뒷받침하는 기능적·과학적 근거가 어느 수준인지 평가합니다.

3. Data Maturity

해당 asset의 개발 단계에 맞는 공개 데이터가 얼마나 충분하고 해석 가능한지 평가합니다.

Target Relevance — Theme / Cluster 근거

E/I Balance와 Neuroimmune은 우선 관심 적응증과 함께 Target Relevance를 정교화하는 SKBP 내부 biology map입니다. 우선 관심 적응증이면 2점을 검토하고, target/MoA가 질환 biology 또는 아래 Theme/Cluster에 직접 연결되면 3점을 검토합니다.

E/I Balance

balance between excitation and inhibition

  • Ion Channel
  • Inhibitory Tone 강화
  • Synaptic Transmission
  • Chloride Homeostasis
  • Network Modulation

Neuroimmune

neuroimmune biology across CNS disease

  • CNS 손상 면역반응
  • 교세포 향상성
  • Cytokine 신경조절
  • 손상/질환 면역조절
  • 말초 면역기관 연결

Evidence Level 안내

확인된 사용자 입력정보 또는 공개자료만 사용합니다. 계획·예상·정황은 현재 사실로 간주하지 않으며, 확인되지 않은 항목은 Unknown으로 표시합니다.

사용자 입력정보
사용자가 표, 텍스트 또는 업로드 자료에 제공한 정보입니다.
공개자료
GPT가 웹서칭을 통해 공식 회사 자료, 논문, 임상시험 registry 등에서 직접 확인한 정보입니다.

TR은 두 근거 유형 중 하나만으로도 평가할 수 있습니다. MoA와 Data에서 2점 이상을 부여하려면 공개 technical evidence 또는 asset-specific 공개 data가 필요합니다.
